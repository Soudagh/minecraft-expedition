# Экспедиция — собственная сборка Minecraft

Полная экспертная сборка для четырёх игроков: требовательные бои, строительство, магия и производство от Create до поздних цепочек GregTech. Формат демо отменён; LV — начало электрической эпохи.

[Промежуточный релиз **0.15.0-combat-sustain-dev**](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.15.0-combat-sustain-dev): 22 главы / 185 записей, общие боссовые этапы, производственные связи Create/Botania/GT/RS и ограничения трёх школ магии и использования найденной экипировки. Добавлены общие открытия девяти этапов и воспроизводимые материалы; игровые испытания боёв продолжаются.

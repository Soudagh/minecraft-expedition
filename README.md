# Экспедиция — собственная сборка Minecraft

Рабочая демо-бета для четырёх игроков: требовательные бои без огнестрельного оружия игрока, строительство, магия и переход от Create к производственным цепочкам GregTech.

**Статус: 0.3.2-dev, прототип для технической проверки. Баланс и полное прохождение ещё не подтверждены.** Не начинайте основной долгосрочный мир до завершения проверки совместимости и генерации.

Файлы сборки и инструкция находятся в [demo-beta](demo-beta/README.md). Состояние работы: [PROJECT_STATE.md](PROJECT_STATE.md).

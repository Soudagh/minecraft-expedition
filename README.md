# Экспедиция — собственная сборка Minecraft

Полная экспертная сборка для четырёх игроков: требовательные бои, строительство, магия и производство от Create до поздних цепочек GregTech. Формат демо отменён; LV — начало электрической эпохи.

[Промежуточный релиз **0.17.0-quest-overhaul-dev**](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.17.0-quest-overhaul-dev): 23 главы / 583 квеста / 627 задач. Добавлены 398 заданий, подробные учебные цепочки всей сборки и отдельная глава строительства. Рабочая книга содержит 553 квеста; 30 исторических записей вынесены в архив. Старые ID и определения задач сохранены.

# Экспедиция — собственная сборка Minecraft

Полная экспертная сборка для четырёх игроков: требовательные бои, строительство, магия и производство от Create до поздних цепочек GregTech. Формат демо отменён; LV — начало электрической эпохи.

[Промежуточный релиз **0.26.0-equipment-balance-dev**](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.26.0-equipment-balance-dev): накопленный баланс промышленности, кухни, лечения и этапов экипировки. Книга: 34 главы / 951 квест / 1000 задач; исправление входа в мир 0.22 сохранено.

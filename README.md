# Экспедиция — собственная сборка Minecraft

Полная экспертная сборка для четырёх игроков: требовательные бои, строительство, магия и производство от Create до поздних цепочек GregTech. Формат демо отменён; LV — начало электрической эпохи.

[Промежуточный релиз **0.18.0-core-quests-dev**](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.18.0-core-quests-dev): 23 главы / 692 квеста / 764 задачи. Добавлены 109 углублённых заданий по Create, Botania, M&A, Hex, Iron’s/Hazen, Refined Storage, HBM и GregTech. Расстояния между учебными карточками уменьшены с 4 до 1,6; основные рубежи расставлены по зависимостям, длинные общие линии скрыты с пояснением требований. Рабочая книга содержит 662 квеста; 30 исторических записей находятся в архиве. Все прежние 583 ID и 627 определений задач сохранены.

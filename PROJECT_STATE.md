## Согласовано

Своя экспертная сборка для 4 игроков, общая команда, у всех 32 ГБ RAM. Отдельный сервер вероятен. RPG: боссы, данжи, экипировка и требовательный бой; без огнестрельного оружия игрока. Строительство, магия, постепенный переход к сложным техническим цепочкам. Нет ранних предметов, позволяющих пропустить прогрессию. Демо заканчивается уведомлением в игре; мир сохраняется и используется в следующих версиях. Пользователь попросил GitHub для установки на другом компьютере и игры с друзьями.

## Реализовано

Правила баланса, уточнённые пользователем, сохранены в `demo-beta/docs/PROGRESSION.md`: ранняя ручная добыча по области, мощные буры к середине, планирование чуть раньше середины, свободный полёт к середине–концу полной игры; связи рецептами; боссы открывают ресурсные этапы/зоны; строительство доступно рано. Раскладка этапов в документе — предложение, ограничения ещё не реализованы в 0.1.1-dev.

- `demo-beta/mods.lock.json`: 38 модов, Minecraft 1.20.1 / Forge 47.4.10 / Java 17, фиксированные URL и хеши.
- Установщик клиент/сервер; обновление в новую копию экземпляра с сохранением исходной.
- Два стабильных предмета KubeJS, рецепты связки Create/Botania/GTCEu.
- 16 квестов, предварительный финальный босс Dead King, финал после турбины и измельчителя LV.
- Серверный флаг завершения и отложенное уведомление игроков офлайн.
- Первичные фильтры лута и оружия Cataclysm.
- Русская инструкция установки и обновления.

- Тест обновления сохраняет байты мира, инвентаря, квестов, команды и scoreboard; исходник не меняется.

## Не проверено / следующий шаг

Пользователь явно принял EULA 6 октября. Локальный сервер с Java 17 создал временный мир и загрузил 16 квестов. Обе разновидности рецепта LV-корпуса проверены через runtime RecipeManager: настроенное ядро требуется и в верстаке, и в сборщике. Клиентский вход, естественное прохождение квестов и отображение уведомления игрокам ещё не проверены. Консольный вызов функции завершения установил флаг; штатное сохранение и остановка выполнены.

Затем: полный аудит лута, торговли и магии (полёт, телепорт, сильные заклинания), уникального оружия, производства/разборки и обходов GregTech. Проверить сложность Dead King вчетвером, ресурсы мира и генерацию данжей. До этого статус только `0.1.1-dev`, основной долгосрочный мир начинать рано.

Сохранение мира: стабильны namespace `kubejs`, два ID предметов, ID квестов `1000000000000001`–`1000000000000010`, task ID `2000000000000001`–`2000000000000010`, scoreboard `exp_progress`, fake player `$demo`, player tag `exp_demo_seen_v1`. Не переименовывать. Миграции проверять на копии мира; не обещать совместимость при удалении модов/смене платформы.

Локальные `.cache`, `.test-server`, `metadata`, `dist` и старый `e9e-audit` не публикуются. E9E больше не основное направление. Не запускать повторный resolve без необходимости: он пересчитывает версии вместо использования lock.

# Физика Create: результат исследования

В 0.7.0-industry-preview НЕ установлена. Проверены официальные страницы, хеши скачанных JAR и META-INF/mods.toml; запуск с полным набором Expedition не проводился. Файлы лежат только в локальном кэше разработчика и не попадают в архив.

## Что делает каждый мод

- **Valkyrien Skies** — физическая основа: движущиеся конструкции из блоков.
- **Clockwork** — соединяет её с Create: самолёты с крыльями/пропеллерами, аэростаты, физические подшипники и другие механизмы. Это физика машин/построек, а не просто реалистично падающий выброшенный меч.
- **Create: Interactive** — позволяет ставить/ломать блоки на движущихся Create-конструкциях, добавляет вложенные механизмы и сход поездов с рельсов. Это отдельный аддон, он не обязателен для Clockwork. По описанию автора интерактивность включается через Interact Me Block, если не изменить серверную настройку.

## Проверенные кандидаты для Forge 1.20.1

| Мод | Версия / Modrinth ID | Ограничения из JAR |
|---|---|---|
| Clockwork | 0.5.6 / fYK8BigB | Create >=6.0.7, VS >=2.4.6, Architectury >=9.1.12, Kelvin >=0.4.0 |
| Valkyrien Skies | 2.4.11 / pOkdwuUh | Create >=6.0.6 при его наличии; Forge 47.4.10 попадает в диапазон |
| Interactive | 1.2.1 / EScBvcOc | Create >=6.0.7, VS >=2.4.0 и <2.5.0 |

Kelvin 0.5.0 встроен в выбранный Clockwork; не нужно скачивать случайный Clockwork с другим Modrinth slug. Правильный проект — create-clockwork. Наш Create 6.0.8 удовлетворяет указанным диапазонам; это ещё не подтверждение совместимости всей сборки.

## Предлагаемая роль в Expedition

Начать будущий отдельный физический тест с VS + Clockwork, затем отдельно оценить Interactive. Для выживания наземную механику можно открыть раньше, воздушную технику — после согласованного боссового этапа ближе к середине. Ранние дешёвые летательные аппараты иначе обходят данжи и ресурсные ограничения.

Перед включением проверить: сохранение/перезапуск собранной конструкции, коллизии на сервере с несколькими игроками, Copycats, шейдеры, Epic Fight, Hex Casting, отсутствие дублирования блоков, работу машин на подвижной платформе. GregTech-машины на движущейся конструкции не считать поддержанными заранее. Рабочий мир сохранять в исходной папке; тестировать отдельную копию.

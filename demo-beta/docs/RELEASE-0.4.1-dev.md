# 0.4.1-dev — шейдеры включены при первой настройке

При установке с `--visuals shaders` установщик автоматически выбирает Complementary Reimagined и включает шейдеры, если config/oculus.properties отсутствует. Существующие настройки не заменяются: личный пакет или выключенное состояние сохраняются при обновлении.

Конфиг является пользовательским, его изменение в игре не мешает будущему переносу. Без профиля shaders и на сервере конфиг не создаётся. Четыре теста установщика прошли, включая эти сценарии. Путь и ключи проверены в Oculus 1.8.0; графический запуск с автоматически созданным конфигом пока не проверен.

Моды, 8 глав/83 записи квестов, рецепты и схема сохранений не изменены относительно 0.4.0. First-person Model показывает тело и существующие анимации; новых анимационных модов в этом исправлении нет. Если вы уже включили шейдеры вручную в 0.4.0, обновляться только ради этого исправления не требуется.

Для новой установки добавьте `--visuals first-person shaders` к обычной команде. Для обновления закройте игру и используйте `--from-instance`, `--stopped` и новую папку назначения.

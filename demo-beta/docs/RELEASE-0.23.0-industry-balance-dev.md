# 0.23.0-industry-balance-dev — общая промышленная цепочка

Локальная версия после 0.22; на GitHub не опубликована. Minecraft 1.20.1 / Forge 47.4.10 / Java 17. Состав и хеши модов, схема сохранений, книга 34/951/1000 сохранены.

11 рецептов HBM дополнительно расходуют один корпус GT: MV для батареи, шреддера, компрессора, обычной центрифуги, химического завода и нефтепереработки; HV для газовой центрифуги и двух крупных турбин; EV для ZIRNOX и rbmk_blank. Все исходные ингредиенты, количества, альтернативы, длительность, энергия, выход и ID сохранены.

Рабочий `hbm_m:converter_block` теперь собирается десятью механическими крафтерами Create: исходные девять материалов и корпус MV. Это связь Create → GT → HBM, без новых конверсий металлов и без изменения энергоэффективности.

Таблица серверных этапов расширена на HBM: базовый цех V, газовая центрифуга/крупные турбины/реакторные блоки VI. Ограничения действуют при размещении и ПКМ; уже поставленная автоматика не останавливается на каждом тике.

[Подробная стоимость и пределы защиты](INDUSTRY-BALANCE.md) · [Обновление установленной 0.22](UPDATE-0.23.md).

Патч содержит 13 игровых файлов: два серверных скрипта и 11 JSON-рецептов. Bootstrap включает исходники, документацию и инструменты; сторонние JAR, миры и включённые QA-пробники в игровые папки не добавляются.

## Подтверждённые проверки

- 16 тестов: 11 установщика, 3 прогрессии и 2 контракта сохранения исходных затрат HBM.
- Forge QA на отдельной копии мира: 276 нативных условий промышленного баланса; полные партии принимаются, отсутствие корпуса/недостача исходного ингредиента отклоняются для всех 11 машин.
- 0 ошибок загрузки/событий KubeJS и 0 неудачных рецептов в финальном запуске. Прежние предупреждения сторонних модов остаются.
- Проверка книги: 10124 условия; 34 главы / 951 квест / 1000 задач; 91 рецепт HBM существует. Пакет книги 873418 байт, без изменения относительно 0.22.
- Файлы архивов сверяются побайтово с исходниками; QA-пробники не устанавливаются в игровые скрипты.

Отчёт: [INDUSTRY-BALANCE-RESULTS-0.23.json](INDUSTRY-BALANCE-RESULTS-0.23.json).

## Пределы проверки

Не проверены собранные производственные линии, потребление энергии реальным многоблоком, графический JEI, бои, полное прохождение и перенос настоящего мира. Нативный матчинг партий и регистрация рецептов не являются прохождением реакторной ветки. Рецепты требуют дополнительных корпусов, поэтому старые тексты заданий описывают исходную часть затрат; книга намеренно сохранена после подтверждения пользователя.

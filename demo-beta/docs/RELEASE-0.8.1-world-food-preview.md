# 0.8.1 — исправление загрузчика при ошибках сертификатов

При установке 0.8.0 на Windows/Python 3.12 возникла `CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate`. Точная причина на компьютере игрока не установлена.

Загрузчик теперь использует системную проверку сертификатов через **truststore**, если пакет установлен. Для установки пакета: `py -m pip install --upgrade truststore`. Затем повторите обычную команду установки. Если truststore отсутствует, работает стандартная проверка Python. Проверка HTTPS не отключается ни в одном режиме.

Также показываются URL скачиваемого файла и понятная инструкция при ошибке SSL. Незавершённые файлы удаляются, SHA-256 проверяется до помещения загрузки в кеш. Восемь тестов прошли: включая отказ без небезопасного повтора, сохранение старого кеша при неверном хеше и обязательную проверку сертификатов стандартным контекстом.

Состав и версии всех 68 модов, конфиги и рецепты не менялись. Схема сохранений остаётся 3. Уже установленная 0.8.0 не требует переустановки: исправление касается только загрузчика. Новую генерацию по-прежнему нельзя автоматически переносить из 0.7.

[Полная инструкция Legacy и исправление для старого архива](INSTALL-LEGACY-WINDOWS.md). Установка truststore может помочь с построением цепочки сертификатов через ОС; она не гарантирует исправления всех сетевых ошибок и не подменяет диагностику Windows игрока.

# Патч 0.26 для установленной 0.22–0.25

Кумулятивный `expedition-0.26.0-equipment-balance-dev-balance-patch.zip` включает промышленный баланс 0.23, рецепты/этапы напитков 0.24, подсказки 0.25 и ограничения рунического оружия и ванильной незеритовой боевой экипировки 0.26. Обновите сервер и всех клиентов одинаково.

1. Полностью остановите игру и сервер, сделайте резервную копию экземпляра.
2. Объедините папку `kubejs` из архива с игровой папкой, заменив одноимённые файлы. Собственные изменения предварительно объедините вручную.
3. Полностью перезапустите игру и сервер. При обновлении с 0.22/0.23 новые настои требуют startup-регистрации.
4. До III общего этапа руническое оружие, ванильные незеритовые меч/топор в активной руке и надетая незеритовая броня возвращается в обычный инвентарь или личный резерв по прежним правилам. Его можно хранить до открытия этапа. Руническая табличка и незеритовые кирка/лопата/мотыга остаются доступными по прежним правилам.

[Оружие и защита](EQUIPMENT-COMBAT-BALANCE.md) · [Еда и лечение](FOOD-SUSTAIN.md) · [Кухня](KITCHEN-BALANCE.md) · [Промышленность](INDUSTRY-BALANCE.md).

Для полного отката восстановите резервную копию. Сохранность новых настоев при удалении их регистрации не гарантируется. Промежуточный релиз опубликован на GitHub. Для установленной 0.21 сначала примените исправление книги 0.22.

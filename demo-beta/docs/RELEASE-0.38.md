# Экспедиция 0.38 — линейная боссовая кампания

Cataclysm теперь открывает DivineRPG только после восьми последовательных побед с Игнисом в финале. Закрыты ранние порталы, переходы и использование экипировки Divine. Souls like Bosses распределены по этапам Divine; будущие победы основной цепочки не копятся заранее.

Добавлены Draconic Evolution и Cracker’s Wither Storm с зависимостями. Завершите основную цепочку и победите Lady Luna, затем Chaos Guardian; после него откроются хаотическая экипировка и Wither Storm. Зачёт Storm требует финального удара по командному блоку.

Перенастроены HP и урон основных боссов, броня и сильное оружие Cataclysm, ступени экипировки Divine. Это начальный профиль для четверых: реальные бои и клиентские EF-комбо ещё требуют игрового прогона. Подробности и ограничения в `docs/LINEAR-BOSS-CAMPAIGN-0.38.md`.

Minecraft 1.20.1 / Forge 47.4.10 / Java 17. 77 клиентских / 72 серверных мода; 38 глав, 1010 квестов, 1060 задач. Прежние 73 модовых записи сохранены без обновлений. Схема сохранений 4; старые победы сохраняются, Cataclysm и Lady Luna не выдаются задним числом. Перед обновлением остановите сервер и сделайте резервную копию. Требуется обновление обеих сторон и полный перезапуск.

Проверки: 43 статических теста, 221 нативное условие, пакет FTB Quests 897980 байт при лимите 1048576. Сервер запускается с обоими финальными модами. Нативный QA проверяет допуск и терминальные состояния, а не полноценную победу над финальными боссами.

Вложения: bootstrap ZIP — установщик клиента; server ZIP — готовый сервер с Forge и 72 модами. Для каждого архива приложен SHA-256. Инструкция: `docs/INSTALL-0.38.md`.

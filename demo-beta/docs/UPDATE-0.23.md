# Локальное обновление промышленного баланса после 0.22

Патч `expedition-0.23.0-industry-balance-dev-balance-patch.zip` предназначен для установленной 0.22 с тем же набором модов. Он содержит два серверных скрипта и 11 JSON-рецептов HBM. Книга, моды и конфиги мира не входят в патч.

1. Полностью остановите игру и сервер, дождитесь выхода Java.
2. Сделайте резервную копию экземпляра.
3. Распакуйте патч в игровую папку: `kubejs` из архива объединяется с существующей `kubejs`. Два одноимённых скрипта заменяются. Если вы меняли их самостоятельно, сначала объедините правки вручную.
4. Полностью запустите игру и сервер заново. Обновите всех игроков вместе.

Старые предметы и машины сохраняются. Новые заказы требуют дополнительные корпуса; в текущие шаблоны RS добавьте корпус соответствующего тира. Для преобразователя используйте механические крафтеры Create. [Точная стоимость и этапы](INDUSTRY-BALANCE.md).

Патч не является публикацией GitHub и не включает полное игровое прохождение. Для отката восстановите два скрипта из резервной копии и удалите только 11 добавленных файлов из `kubejs/data/hbm_m/recipes`: battery, shredder, compressor, centrifuge, chemical_plant, refinery, gas_centrifuge, turbine, industrial_turbine, zirnox, rbmk. Если эти пути существовали до обновления, восстановите их прежние версии вместо удаления.

# Обновление 0.21 → 0.22: ошибка «Неверные данные игрока»

FTB Quests отправлял книгу больше лимита одного пакета (1 048 576 байт). Это подтверждено стеком ошибки и воспроизведено на исходной книге 0.21. Удалять данные игрока и мир для этого исправления не нужно.

Скачать [патч квестов 0.22](https://github.com/Soudagh/minecraft-expedition/releases/download/v0.22.0-quest-sync-fix-dev/expedition-0.22.0-quest-sync-fix-dev-quests-patch.zip).

1. Полностью закройте Minecraft; если есть отдельный сервер, остановите его.
2. Сделайте резервную копию экземпляра сборки, включая `saves` и `config`.
3. Распакуйте `expedition-0.22.0-quest-sync-fix-dev-quests-patch.zip` в корень установленного экземпляра — туда, где лежат `mods`, `config`, `kubejs`. Согласитесь на замену файлов внутри `config/ftbquests/quests`.
4. Если играете на отдельном сервере, примените тот же патч в его корне и на клиентах.
5. Запустите игру. Сначала проверьте создание временного одиночного мира и вход в него; затем проверьте копию прежнего мира.

Патч содержит только книгу квестов и эту инструкцию. Моды, рецепты и данные сохранений не заменяются. Все 951 квест, 1000 задач, их ID, связи и фиксированные значки сохранены. Повторяющиеся общие инструкции перенесены во вступления; повторная практика ссылается на предыдущее предметное задание. Порядок действий и критерии результата сохранены.

Нативный пакет исправленной версии: 873 418 байт, запас 175 158 байт. Проверен конструктор пакета на Forge 47.4.10 / Java 17 и 10 124 условия загруженной книги. Вход через графический клиент и перенос командного прогресса ещё не проверены. В логе друга был Forge 47.4.23; штатная версия сборки — 47.4.10, но найденный сбой вызван именно размером пакета.

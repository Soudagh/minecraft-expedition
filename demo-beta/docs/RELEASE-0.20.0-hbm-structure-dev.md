# 0.20.0-hbm-structure-dev

HBM разделён на пять производственных глав: площадка и металлургия, пресс и оснастка, компоненты и обмотки, сборщик и электроника, эксплуатация и контроль. Всего 147 карточек HBM; структура и количество заданий приведены в [маршруте HBM](HBM-QUESTS.md), [схема пяти глав](HBM-CONNECTIONS-0.20.svg).

Добавлены 24 новых упражнения: варианты рудной стали, заказ сплавов, пластины сплава, золотой провод и обмотки, резерв штампов, серийные компоненты, большие заказы трёх видов схем, счётчик Гейгера и приёмка цеха другим игроком. Составы сверены с JSON установленного HBM 0.2.1-alpha; [источники](HBM-QUEST-SOURCES-0.20.json).

77 смешанных карточек во всей книге разделены на предметную и практическую; 50 из них относятся к HBM. Предметный квест теперь содержит только предметы, с постоянным значком первого изделия. Следующий квест «Практика» содержит только галочку. Продолжение требует выполненную практику, поэтому разделение не удаляет прежнее условие завершения. Книга не измеряет работу станков автоматически.

Всего 27 глав / 860 квестов / 907 задач, включая 30 архивных квестов. Все 759 прежних ID квестов и 869 определений задач 0.19 сохранены; старые задачи-галочки перенесены в новые практические квесты с теми же ID. Проверка сохранности ID не подтверждает перенос реального командного прогресса; обновляйте остановленную копию экземпляра с резервной копией.

## Проверки

23 автоматических теста: установщик, прогрессия, отсутствие циклов, неизменность исторических задач, однородные типы предметных/практических карточек, постоянные предметные значки, сохранение требования практики после разделения, порядок пяти глав, геометрия и детерминированная генерация. [Отчёт разделения задач](QUEST-TASK-SPLITS-0.20.json), [инвентарь книги](QUEST-CURRICULUM-0.20.json), [раскладка](QUEST-LAYOUT-0.20.json).

Нативная проверка выполняется на отдельном Forge QA-сервере `instances/hbm-structure-0.20-check`, Java 17, localhost:25590, копия диагностического мира. Пройдено 9120 нативных условий: 27 глав / 860 квестов / 907 задач, 493 предметных ID, 1082 зависимости и 560 постоянных предметных значков. KubeJS: 0 ошибок загрузки и событий, 0 неуспешных рецептов; внешние upstream-предупреждения остаются. Probe сверяет координаты и зависимости, типы задач и реально загруженные постоянные предметные значки. [Результат книги](QUEST-BOOK-RESULTS-0.20.json), [40 рецептов HBM](HBM-QUEST-RESULTS-0.20.json). Графический Minecraft-клиент, исполнение новых цепочек в выживании и перенос настоящей команды остаются игровой проверкой.

Коммит и тег 0.20 загружены на GitHub. ZIP-релиз не создан: автоматическая проверка разрешений отклонила загрузку архива и запросила подтверждение конкретного файла и репозитория. Архив bootstrap содержит исходники, документацию, генераторы и overrides; диагностические миры и сторонние JAR не включены. Состав модов, рецепты и схема сохранений 4 сохранены.

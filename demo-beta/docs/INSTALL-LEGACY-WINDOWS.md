# Установка «Экспедиции 0.19» в Legacy Launcher — Windows

Для друга, который устанавливает сборку впервые. Нужны интернет, Windows 64-bit и Legacy Launcher. Сборка: Minecraft 1.20.1 + Forge 47.4.10 + Java 17. Для первой установки создаём временный мир. Перенос 0.9 → 0.19 проверяем на копии; из 0.8 и более ранних версий нужен новый мир.

Инструкция сверена с документацией Legacy. Весь путь на Windows вручную пока не проходили; запуск сервера и установка файлов сборки проверены.

## 1. Подготовь Python и Java

- Установи Python 3.10 или новее с https://www.python.org/downloads/windows/ . Если установщик предлагает Python Launcher (`py`), включи его.
- Установи Java 17, 64-bit. Например, Temurin: https://adoptium.net/temurin/releases/?version=17 — выбери Windows, x64, JDK, установщик MSI. Запомни папку установки: позже понадобится файл `bin\java.exe` внутри неё.
- Если эти программы уже установлены, повторная установка не нужна. Java, на которой работает сам лаунчер, может отличаться от Java для Minecraft: для игры ниже выбираем именно 17.

## 2. Распакуй и установи сборку

1. Скачай [bootstrap-архив 0.19](https://github.com/Soudagh/minecraft-expedition/releases/download/v0.19.0-hbm-quests-dev/expedition-0.19.0-hbm-quests-dev-bootstrap.zip) из [промежуточного релиза](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.19.0-hbm-quests-dev). Архив старой 0.9 не содержит новые квесты. Если используешь исходники 0.19, папка сборки называется `demo-beta`.
2. Нажми на ZIP правой кнопкой → «Извлечь всё». Нельзя запускать установку прямо из ZIP.
3. Открой распакованную папку `expedition-demo`. В ней должны быть `README.md`, `mods.lock.json` и папка `tools`.
4. Щёлкни по адресной строке Проводника, введи `powershell` и нажми Enter.
5. Проверь Python командой `py --version`: нужна версия не ниже 3.10. Затем вставь:

```powershell
py tools/install.py --side client --visuals shaders --destination "$env:USERPROFILE\Games\Expedition-0.19"
```

Дождись строки `Prepared:`. Загрузчик скачает моды и проверит файлы. Скопируй полный путь после `Prepared:` — он понадобится дальше. Обычно это `C:\Users\ИМЯ\Games\Expedition-0.19`.

Папку `Expedition-0.19` заранее создавать не нужно. Если она уже существует, выбери другое имя, например `Expedition-0.19-new`, и дальше используй именно его. Не удаляй папку, если в ней есть нужные данные.

Если команда `py` не найдена, попробуй `python --version`. Если это Python 3.10+, замени только `py` в команде установки на `python`.

## 3. Укажи папку в Legacy

1. Открой Legacy → «Дополнительно» → «Настройки лаунчера и игры» → вкладка «Minecraft».
2. Сохрани прежнее значение «Директория», если пользуешься другой сборкой.
3. В «Директория» вставь полный путь из строки `Prepared:`.
4. Для этой отдельной папки выбери **«Не использовать отдельные папки»**. Иначе Legacy может искать моды в дополнительной папке `home`, а не там, куда мы их установили.
5. Сохрани настройки. Через значок папки на главном экране проверь: открывается именно `Expedition-0.19`, в ней видны `mods`, `config`, `kubejs`.

Источник: https://docs.llaun.ch/launcher/subfolders

## 4. Установи точную версию Forge

Нужен **Forge 47.4.10 для Minecraft 1.20.1**. Не выбирай просто любую строку «Forge 1.20.1».

1. Перед первым запуском настрой Java 17 по шагу 5 ниже. В Legacy выбери обычную Minecraft 1.20.1, один раз запусти до главного меню и закрой игру. Мир на этом шаге не создавай. Это подготовит базовые файлы в выбранной папке.
2. Скачай официальный Forge Installer:
   https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.10/forge-1.20.1-47.4.10-installer.jar
3. Закрой Legacy. Открой скачанный JAR двойным щелчком.
4. В установщике выбери **Install client** и укажи ту же папку `Expedition-0.19` из шага 2. Дождись завершения.
5. Открой Legacy снова. В списке версий выбери `1.20.1-forge-47.4.10`. Если версия скрыта, включи показ «Модификации» в настройках списка версий.

Если JAR не открывается, в PowerShell набери `& `, перетащи из Проводника файл `java.exe` из установленной Java 17, допиши ` -jar `, затем перетащи скачанный Forge Installer и нажми Enter. Пути с пробелами заключи в двойные кавычки. Пример формы команды (пути замени своими):

```powershell
& "C:\папка-Java-17\bin\java.exe" -jar "C:\папка-загрузок\forge-1.20.1-47.4.10-installer.jar"
```

Источник: https://docs.llaun.ch/mods/forge

## 5. Выбери Java и память

В настройках Legacy на вкладке «Minecraft»:

- Java/JRE → настройка пользовательской Java → «Обзор» → выбери `bin\java.exe` из папки Java 17. Не выбирай Java 8 или случайную установленную Java.
- Память: начни с **8192 МБ**, если на компьютере 16 ГБ ОЗУ или больше. Если всего 8 ГБ, не отдавай игре всю память: можно попробовать 4096–5120 МБ без шейдеров, но комфортная работа этой сборки на таком компьютере не подтверждена.
- При возвращении к другой версии Minecraft верни её папку и подходящую Java: эти настройки Legacy могут действовать и на другие версии.

Источники: https://docs.llaun.ch/launcher/settings и https://docs.llaun.ch/faq/custom-java

## 6. Запусти игру

Нажми кнопку запуска с выбранной версией `1.20.1-forge-47.4.10`. Первый запуск и создание мира могут занять несколько минут.

Проверь список Mods: там должны быть HBM's Nuclear Tech Modernized, Jade, Hazen 'n Stuff, Iron's Spells, Refined Storage, Farmer's Delight, Brewin' and Chewin', Terralith и Tectonic. Число в списке может быть больше количества JAR: некоторые содержат встроенные зависимости.

- Для одиночной проверки создай **новый** мир. Миры из 0.8 и более ранних версий сюда не переносим: удалены AE2, GTMThings и GT--.
- Для общей игры: «Сетевая игра» → «Добавить сервер» → адрес, который даст организатор. На сервере и у игроков должна быть одна версия сборки. Параметры аккаунта и доступ к серверу уточни у организатора.
- Шейдер Complementary установлен и включён по умолчанию. Если тормозит, отключи его через настройки графики → меню шейдеров. OptiFine дополнительно ставить не нужно.

## Ошибка SSL / CERTIFICATE_VERIFY_FAILED

Если Python сообщает `unable to get local issuer certificate`, он не смог проверить цепочку сертификатов HTTPS. Это происходит при скачивании, ещё до запуска игры; причина может быть в цепочке сервера, сертификатах Windows или проверке HTTPS вашей сетью/антивирусом.

Для установщика 0.9 выполните в том же PowerShell:

```powershell
py -m pip install --upgrade truststore
py tools/install.py --side client --visuals shaders --destination "$env:USERPROFILE\Games\Expedition-0.19"
```

Установщик автоматически использует установленный truststore для системной проверки сертификатов. Проверки HTTPS и SHA-256 остаются включены.

Если у вас ещё старый архив 0.8.0, после установки truststore можно запустить его так:

```powershell
py -c "import sys, truststore, runpy; sys.path.insert(0, 'tools'); truststore.inject_into_ssl(); runpy.run_path('tools/install.py', run_name='__main__')" --side client --visuals shaders --destination "$env:USERPROFILE\Games\Expedition-0.19"
```

При SSL-ошибке загрузки папка назначения ещё не создаётся: повторите команду с прежним путём. Если она уже существует по другой причине, выберите новое имя. Уже успешно скачанные и проверенные файлы повторно не загружаются.

Если сама команда pip не устанавливает truststore или ошибка остаётся, пришлите полный вывод и строку `Downloading:` (в 0.9). Не отключайте проверку сертификатов. Без доступа к Windows этого компьютера гарантировать устранение причины нельзя.

Источник: [документация truststore](https://truststore.readthedocs.io/en/stable/).

## Если не получилось

| Что видишь | Что проверить |
|---|---|
| `can't open file ... install.py` | PowerShell открыт в папке `expedition-demo`, где есть `tools`, а ZIP полностью распакован |
| `Destination must not exist` | Выбери новое имя папки назначения и укажи его также в Legacy |
| Нет модов, запустилась обычная игра | Выбрана Forge 47.4.10, директория правильная, отдельные подпапки отключены |
| Ошибка загрузки/хеша | Сохрани полный текст ошибки; проверь интернет. Повтори установку в новую папку, если предыдущая уже появилась |
| Forge не находит базовую игру | Проверь путь и сначала запусти обычную 1.20.1 в той же директории |
| Вылет или зависание | Пришли организатору `logs\latest.log` из папки игры и свежий файл из `crash-reports`, если он есть; также укажи действие перед ошибкой |

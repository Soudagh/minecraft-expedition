# 0.25.0-kitchen-sustain-dev · локальная версия

К двум ромам и настоям добавлены клиентские подсказки: расход насыщения Sweet Heart, общие этапы II/III, действительные названия материалов и партия из четырёх кружек. Промышленный баланс 0.23 и рецепты напитков 0.24 входят в кумулятивный патч.

Проверено сочетание Sweet Heart/Nourishment/Comfort и прямое лечение Iron’s. Sweet Heart тратит насыщение; Nourishment при нулевом насыщении поддерживает медленную естественную регенерацию без потери голода. Вместе с Comfort в заданном QA-сценарии это 10 HP за 20 секунд. Численные настройки лечения сохранены; выживаемость команды в бою ещё не измерялась.

Нативная QA: 38 проверок еды/лечения, восемь сценариев; повторно кухня/энергия 299, промышленность 276, книга 10124. Startup/server-скрипты и рецепты без ошибок. Heal I: 5 HP, 30 маны, откат 30 с; Greater Heal: полное здоровье, 150 маны, откат 60 с после синхронизации конфигурации. FakePlayer и заданный порядок вызовов не воспроизводят полный тик игрока или сетевой клиент. Новые клиентские подсказки проверены синтаксически и по доступному API KubeJS; визуальная проверка ещё нужна.

Моды, ID предметов, квестов и задач, данные общего прогресса сохранены. На GitHub версия не опубликована.

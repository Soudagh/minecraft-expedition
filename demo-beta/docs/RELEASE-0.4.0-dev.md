# 0.4.0-dev — ветки развития и необязательная графика

Книга расширена с 2 глав / 32 записей до 8 глав / 83 записей. Добавлены экспедиции и снабжение, практическая мастерская Create, Mana and Artifice, Hex Casting, Botania и индустриальная подготовка. Всего 54 предметных задания, 16 ручных упражнений, 12 информационных карточек и одно старое испытание Cataclysm. Предметное задание проверяет наличие вещи; ручное упражнение не является автоматической проверкой действий.

Старые идентификаторы квестов, задач, условий и флаг завершения сохранены. Старый финал теперь обозначен как архивный рубеж, а его уведомление не объявляет прохождение новой полной линии. Завершившим старое демо повторное сообщение не выдаётся. Cataclysm остаётся необязательным вне архивного испытания.

Базовый набор — прежние 48 модов. Необязательные клиентские профили: `first-person` (First-person Model 2.7.3) и `shaders` (Oculus 1.8.0 + Complementary Reimagined r5.9.3). Оба вместе дают 50 внешних JAR и один ZIP шейдера. Зависимости Not Enough Animations и Embeddium уже включены. Подробности: [графика](VISUALS.md).

## Баланс

[Новый проект ресурсных переходов](BALANCE-0.4.md) сохраняет RPG первой половины и ставит переход к LV после Relic Annihilator. **Эти замки ещё не действуют.** В этом обновлении нет новых боевых множителей или изменения цен рецептов. Книга не гарантирует месяцы игры; реальный темп требует серверного учёта побед, переработки рецептов/лута и тестов на четверых.

## Проверка

- Четыре теста установщика: сохранения/данные игроков/FTB, отказ при опасных путях и изменённых управляемых файлах, генерация совместимости SLB, перенос/удаление необязательной графики без изменения исходника.
- Все прежние ID и определения задач сравнены с 0.3.2: совпадают. Новые зависимости проверены на отсутствие циклов и неизвестных ID.
- На копии старого тестового мира сервер Forge 47.4.10 / Java 17 запустился, FTB загрузил 8 глав / 83 записи. Все 50 уникальных предметов из задач проверены через реестр запущенного сервера: ни одного пустого ItemStack.
- Установлен отдельный клиентский экземпляр с обоими визуальными профилями; хеши совпали. Графический клиент и отображение интерфейса квестов не запускались.
- При первой попытке теста песочница запретила открытие локального порта; зависший тестовый процесс остановлен. Повторная попытка до его остановки не получила блокировку мира. Успешный запуск выполнен после освобождения папки с разрешённым localhost. Исходный экземпляр не менялся.

Остаются известные нефатальные сообщения модов о клиентских классах на dedicated server и сбоях проверки обновлений. Это не утверждение об отсутствии всех ошибок совместимости. Бои, окна атак, FPS и отображение шейдеров требуют игрового теста.

## Обновление

Схема сохранений по-прежнему 2. Закройте игру и сервер. Установите в новую папку через `--from-instance` и `--stopped`; предыдущая папка остаётся для отката. Существующие миры не пересоздаются. Для графики добавьте `--visuals first-person shaders`; серверу этот параметр не нужен. Полный перезапуск обязателен, `/reload` не используйте.

# 0.19.0-hbm-quests-dev

Добавлены 67 подробных квестов: 43 для HBM и по 4 для Create, Botania, Refined Storage, Mana and Artifice, Hex Casting, Iron’s/Hazen. Всего 23 главы, 759 квестов и 869 задач, включая 30 архивных квестов. HBM вырос с 30 до 73 заданий. Все 692 квеста и 764 определения задач 0.18 сохранены.

[HBM](HBM-QUESTS.md) теперь ведёт через доменную печь, сталь, красную медь и сплавы к трём типам штампов, проводам, кремниевым основам, микросхемам, лампам, катушкам и моторам. Следующий проект — сборщик со стальной наковальни и отдельные партии аналоговой, интегральной и развитой электроники. Эксплуатация включает приём выхода, два замера производства, устранение одного узкого места и итоговый заказ с резервом. Финальное упражнение требует передать цех другому игроку по инструкции.

Новые предметные цели задают реальные количества, не расходуют вещи и сопровождаются отдельной ручной отметкой практики. Все новые задания HBM требуют командный этап V. Зависимости обучения не заменяют рецепты MV, условия наковальни и питание. JSON рецептов установленного HBM 0.2.1-alpha разобраны локально, с сохранением [имени JAR, SHA-256 и составов](HBM-QUEST-SOURCES-0.19.json). Аналоговая/интегральная/развитая схемы используют разные полуфабрикаты: предыдущая схема не объявлена ингредиентом следующей.

Другие проекты углубляют заказы точных механизмов Create, снабжение рун и ядер Botania, вложенные шаблоны и дефициты RS, отладку стека Hex, сравнение одного изменения заклинания M&A и практику серии кастов Iron’s. Для каждого шага указаны подготовка, действия, критерий результата и диагностика.

## Проработка связей

HBM перестроен в граф из 43 новых заданий и 68 видимых внутренних связей. Металлургия, оснастка и компоненты сходятся к сборщику; аналоговая линия не требует микросхем, а печь требует готовые медные пластины. Наковальня и пресс связаны с корпусом/поршнем MV в главе GregTech; проект ядер Botania — с механическим ядром пролога. Практические задания теперь требуют описанное рабочее место, даже если оно появляется позже первого шага ветви. У RS три типа заготовок и их обработка независимы; готовый простой процессор не требуется для изготовления улучшенного. Уточнены 20 связей вводных заданий, удалены 130 повторных требований углублённых ветвей с сохранением достижимости. [Схема HBM](HBM-CONNECTIONS-0.19.svg), [отчёт связей](QUEST-CONNECTIONS-0.19.json). Все определения задач сохранены.

## Проверено

- Валидатор: уникальные ID, существующие ссылки, отсутствие циклов; все 692 прежних квеста и 764 задачи HEAD сохранены.
- 20 автоматических тестов: установщик, прогрессия, геометрия книги и повторяемая генерация. Новые ветви используют компактную раскладку: HBM 1,8 для разветвлений, остальные строки 1,6; межветвевые требования названы в описаниях.
- Отдельный Forge-сервер `instances/hbm-quests-0.19-check`, Java 17, localhost:25589, копия диагностического мира: загрузил 23 главы / 759 квестов / 869 задач. [6919 условий проверки](QUEST-BOOK-RESULTS-0.19.json), включая точный состав всех 959 зависимостей, реальные координаты, видимость линий и 487 предметных ID.
- [28 рецептов HBM](HBM-QUEST-RESULTS-0.19.json) присутствуют в нативном RecipeManager после KubeJS, включая три заменённых рецепта сборки. Это проверка наличия рецептов, не исполнения производственной цепочки.
- KubeJS: 0 ошибок загрузки и событий, 0 неуспешных рецептов; 38 добавлено, 56 удалено, 222 изменено. Предупреждения внешних модов сохраняются.

Полное прохождение в выживании, интерфейсы машин, работа питания HBM и внешний вид книги в графическом клиенте остаются игровой проверкой. Изменения рецептов, состава JAR и схемы сохранений не внесены; схема остаётся 4. Probe-файлы лежат только в tools, не в распространяемых overrides.

Генерация: `python3 tools/build_quests.py`. Новые цепочки: `tools/deep_curriculum.tsv` и `tools/deep_quests.py`, стабильные номера записей с ID 19…/2A…. [Инвентарь](QUEST-CURRICULUM-0.19.json), [раскладка](QUEST-LAYOUT-0.19.json).

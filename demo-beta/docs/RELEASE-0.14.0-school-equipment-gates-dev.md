# 0.14.0-school-equipment-gates-dev

Сильные способности Mana and Artifice и Hex Casting теперь требуют общих боссовых этапов. Найденная или переданная закрытая экипировка также проверяется при использовании. Подробные пороги и поведение — [школы и экипировка](SCHOOL-EQUIPMENT-GATES.md).

- M&A: tier 3 / 4 / 5 → III / VI / VII; Soar, Eldrin Flight, Blink → VII; Icarian Flight → не ранее IV. Штатные требования Occulus и фракций сохраняются.
- Hex: сильное перемещение, Greater Sentinel и Flay Mind → VII; взрывы, молния и добыча в кругах → VI. Ручная добыча ранняя; штатные расходы и запреты сохранены.
- Активные слоты брони и рук: террасталь, незеритовое оружие Simply Swords, книги Iron’s, поздняя магическая/техническая броня и уникальное оружие требуют своих этапов. Winged Tiara проверяется через Curios.
- При полном инвентаре снятые предметы хранятся в Forge PlayerPersisted; возвращаются при освобождении места, с полным NBT. KubeJS persistentData не используется для резерва: это отдельное хранилище.
- Квесты уточняют ограничения; 22 главы / 185 записей / 220 задач, все определения задач и идентификаторы сохранены. Внешние моды, SHA256 и схема сохранения 4 не изменены. Рецепты межмодовой синергии 0.12–0.13 сохраняются.

## Проверки

На отдельной копии тестового мира проверены 186 действий Hex, сохранение конфигурации и расходов, нативный precheck полёта до/после открытия; события 122 компонентов M&A на границе открытия; CurioEquipEvent для тиары; полное сохранение и восстановление NBT резерва игрока. Финальный запуск: 797 успешных проверок, включая 10 вариантов GT-брони и снятие уже надетой тиары из настоящего контейнера Curios; ошибок событий и неуспешных рецептов нет. Сервер сохранён и остановлен.

12 тестов установщика и контрактов прогрессии проходят. Валидатор подтверждает отсутствие циклов и сохранение 99 исторических квестов/108 определений задач относительно HEAD; отдельно совпадают все 185 наборов задач с проверочным экземпляром 0.13.

Проверки используют FakePlayer и собственные API модов. Настоящие бои, клиентское управление, полные круги/упакованные Hex, смерть/возрождение и повторный вход реального игрока ещё не проверены. Hazen и отдельные награды, навыки Sword Soaring, точное равенство урона/лечения и финальный промышленный проект остаются открытыми.

## Установка

Нужен полный перезапуск для startup scripts. В QA datapack reload на 5 ГБ завис с watchdog/GC pressure; безопасный `/reload` не подтверждён. Прежняя проблема памяти генерации нового мира не устранена. Тестовое обновление выполняйте на копии по инструкции Legacy Launcher.

Bootstrap содержит исходники, конфиги и загрузчик, без сторонних JAR, миров и QA-скриптов. Версия подготовлена локально, в GitHub Releases не опубликована.

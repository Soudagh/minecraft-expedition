# Expedition 0.35 · Divine RPG, команда и приват

Локальная сборка добавляет DivineRPG 1.10.7.5 и Open Parties and Claims 0.32.7. Состав зафиксирован SHA-256: 73 мода для клиента, 68 для сервера. Minecraft 1.20.1 / Forge 47.4.10 / Java 17, схема сохранений 4. Публикация GitHub в этой работе не выполнялась.

- Новая отдельная глава Divine RPG: 40 квестов. Всего 35 глав, 991 квест, 1040 задач. Все 951 прежний квест и 1000 определений задач сохранены.
- 14 рецептов связывают Divine с Create, Botania и HBM. Шесть рецептов дробления работают с фактическими ID `*_ore` и `*_ore_deepslate`. Серверные ограничения входа связывают восемь измерений с общей кампанией; выход в обычный мир свободен. Основные комплекты ограничены по этапам; 37 мечей/клинков получили тип Epic Fight.
- Очищены 9 шаблонов HBM и 51 таблица лута. Проверены все эффективные шаблоны/таблицы из зафиксированного JAR, размеры и сохранение промышленной палитры. Дополнительный фильтр LootJS закрывает оружейный лут сундуков.
- Xaero Minimap и World Map теперь стоят на сервере. Open Parties and Claims использует FTB Teams, общий приват и его цвет; встроенные отдельные команды OPAC отключены.
- Команда `/teammap` хранит до 64 меток в NBT FTB Teams, проверяет авторство/ранг удаления и изолирует чужие команды. Полученные сообщения импортируются в Xaero с подтверждением пользователя; удаление/редактирование локальных копий выполняется на клиенте.
- Исправлен upstream-тег `minecraft:impermeable` Divine с несуществующими `stained_glass2..8`: сохранены 240 ID из ванильного тега и остальных установленных модов.

Статические проверки: установщик 11, прогрессия 3, новая интеграция 3, размещение/детерминизм книги 3, текстовый бюджет 2, этапы HBM 4, структура книги HBM 3, связи книги 5, промышленность 2, кухня 2. Все перечисленные проверки пройдены. Проверка истории книги отдельно подтверждает неизменность старых задач.

Изолированный QA: `instances/divine-team-0.35-check`, localhost:25600, Java 17, Xmx5G. Нативный сценарий: 85 проверок, 32 зарегистрированных предмета, 14 рецептов, конфиг OPAC, видимость участника/постороннего через встроенный трекер Xaero, команды меток от искусственных игроков, запрет удаления чужой метки участнику, изоляция чужой команды, NBT round trip, запреты/разрешения событий перехода и использование общих этапов экипировки. Пакет FTB Quests реально сконструирован: 888 537 байт при лимите 1 048 576. Отчёты: `DIVINE-TEAM-RESULTS-0.35.json`, `QUEST-SYNC-RESULTS-0.35.json`, `HBM-PEACEFUL-0.35.json`.

В первых QA-итерациях исправлены вызов схемы рецептов Create, названия глубинных руд, вложенные ключи OPAC и обращения к API в тестовых фикстурах. Начальная попытка запуска без разрешения на localhost не смогла открыть порт; следующий процесс увидел удерживаемую блокировку. Оба неудачных QA-процесса завершены; последующие полноценные запуски остановлены штатно с сохранением всех измерений. До релиза проверки повторены на исправленных игровых файлах.

Ограничения: не запускался графический клиент; реальный вход/выход через порталы, интерфейс импорта меток, командное выделение территории и защита от специальных взрывов HBM ещё не проверены в многопользовательской игре. Серверные события тестировались без фактического перемещения игроков. Боевая анимация, встроенные способности Divine и полный баланс прохождения требуют клиентского QA. Нативная модель FTB Teams тестировалась на созданных фикстурах; реальный вход/приглашение игроков не имитировались. Существующие upstream-сообщения Mana and Artifice, Iron’s Spellbooks и отражения клиентских классов на сервере остаются; успех не означает отсутствие всех upstream-ошибок.

[Установка, обновление и команды](UPDATE-0.35.md). Bootstrap не включает JAR, миры, кэши и искусственные QA-данные. Готовая клиентская папка создана отдельно: `instances/expedition-client-0.35`; в ней нет QA-сценариев.

Первичные источники: [Divine RPG](https://github.com/DivineRPG/DivineRPG), [Open Parties and Claims](https://github.com/thexaero/open-parties-and-claims). Фактическая совместимость и имена API сверены по зафиксированным JAR.

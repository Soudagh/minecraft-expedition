# 0.10.0-full-progression-dev

Полный формат сборки заменяет демо. LV — начало электрической эпохи; новые задания охватывают установленный состав до поздней индустрии UV. Это рабочая версия, не подтверждённый игровой баланс.

## Изменения

- 11 новых глав / 61 предметное задание; вся книга — 20 глав / 160 записей / 195 задач с архивом и атласом. Все прежние 99 квестов и 108 определений задач сохранены.
- Кухня FD/B&C, RS/автокрафт, HBM, GT LV–UV, поздняя Botania, Iron’s/Hazen, энергетика и логистика. NanoMuscle/QuarkTech — боковые цели, они не блокируют дальнейшую промышленную цепочку.
- Botania flight tiara требует корпус EV вместо ender air bottle. Ресурсы Гайи и восемь рецептов внешнего вида сохранены.
- RS wireless grid требует корпус HV вместо advanced processor. Базовый контроллер остаётся на LV.
- Старый квест LV больше не вызывает финал демо. Сохранены старые scoreboard/теги, отключены прежние уведомления при входе.
- [FULL-BALANCE.md](FULL-BALANCE.md) задаёт рабочие этапы всех направлений, экономику, подготовку к боссам и программу проверки. [QUESTS-FULL.md](QUESTS-FULL.md) описывает новую книгу.

## Совместимость

Все записи модов/версии/хеши идентичны 0.9. Схема сохранений 4 сохранена. Старые экземпляры не изменены. Обновление 0.9 → 0.10 только в копию через установщик; автоперенос из 0.8 и более ранних версий запрещён. Директория `demo-beta` и старые имена главы/архива сохранены как технические пути.

## Проверено

- Статический граф: уникальные ID, существующие зависимости, отсутствие циклов; сохранены все прежние quest/task definitions. Повторная генерация даёт те же файлы.
- 9 тестов установщика проходят; записи модов и save schema сравнены с 0.9 и не изменены.
- Forge 47.4.10 / Java 17 на отдельной копии тестового мира 0.9: 20 глав / 160 квестов, все 151 уникальный предмет существуют в runtime-реестре.
- 7/7 server scripts, включая один локальный QA-скрипт, загружены без ошибок; 5 added / 51 removed / 177 modified / 0 failed recipes. В поставке 6 server scripts; QA-скрипт в неё не входит.
- Конечный RecipeManager подтвердил EV в базовой тиаре, HV в wireless grid, прежний LV в controller и MV/поршень/настроенное ядро в HBM press.
- Тестовая папка `instances/full-progression-0.10-check`; итоговый лог `startup-010-final.log`. Выполнены `save-all flush` и `stop`.

## Ограничения

Общие серверные открытия девяти этапов по настоящим победам ещё не реализованы. Атлас не засчитывает убийства. Книга не проверяет работающий мультиблок, заряд, содержимое шаблона, применение заклинания и прохождение всей игры. Новые recipe requirements не запрещают пользоваться подаренной вещью и не закрывают все альтернативные источники полёта/магии.

Графический клиент, естественное прохождение новых рецептов, бои вчетвером и длительность кампании не проверены. В текущих модах остаются нефатальные предупреждения M&A/client-class и ошибки двух таблиц лута Iron’s; их исправление не входит в эту версию. Серверный прогон книги не означает чистый лог всех модов.

Первый fresh-world прогон при `-Xmx5G` завершился OutOfMemoryError в генерации/чтении NBT структур. Это отдельный открытый вопрос запуска нового мира; успешная загрузка копии уже сгенерированного мира не подтверждает, что генерация нового мира исправлена. Отдельная тестовая папка и упавший мир сохранены для диагностики.

Архив создаётся локально `python3 tools/package.py`; публикация этой версии в GitHub Releases не выполнена.

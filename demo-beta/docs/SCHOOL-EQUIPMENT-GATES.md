# Школы магии и найденная экипировка · 0.14

Ограничения связаны с общим этапом мира `exp_stage`, который открывают девять боссовых побед. Начальная практика всех школ доступна. Это первый потолок доступа, а не подтверждённое равенство урона и лечения в бою.

## Mana and Artifice

Серверное `SpellCastEvent` проверяет `ISpellDefinition.getTier(level)` и компоненты составного заклинания. Tier 3 требует III, tier 4 — VI, tier 5 и выше — VII. Для Soar (`mna:components/glide`, Java ComponentFlight), Eldrin Flight и Blink установлен минимум VII; для Icarian Flight — IV. Всегда применяется более высокий порог, включая tier всего заклинания. Occulus, фракции и собственные требования мода сохраняются.

Нативный SpellCaster вызывает событие до применения эффекта; отмена возвращает CANCELED_BY_EVENT. Обычный путь не списывает ресурс после неуспешного результата. Клиентские анимации и все альтернативные пути применения, ритуалы, конструкты и эффекты уже действующих заклинаний отдельно не проверены.

## Hex Casting

Через публичный `HexConfig.ServerConfigAccess` дополнительные ограничения объединены со штатными запретами. Все прочие методы делегируются исходной конфигурации: расходы среды, лимиты операций, разрешённые измерения и прочие параметры сохраняются. На остановке сервера исходная конфигурация восстанавливается; нужен полный перезапуск для установки startup scripts.

| Действие | Минимум |
|---|---:|
| Flight по времени/дальности, Blink, Greater Teleport | VII |
| Greater Sentinel, Flay Mind (`brainsweep`) | VII |
| Explosion, Fireball, Lightning | VI |
| Break Block при ручном исполнении | 0 |
| Break Block в кругах | VI |

Применяется собственная проверка разрешения действия Hex, включая `CastingEnvironment.precheckAction`. Для кругов действует дополнительный predicate мода. Реальная работа круга/упакованного заклинания и клиентский интерфейс ещё требуют игровой проверки.

## Использование экипировки

| Вещь в активном слоте | Минимум |
|---|---:|
| Террастальная броня Botania | III |
| Незеритовое оружие Simply Swords, Diamond Spell Book | III |
| Netherite Mage Armour и Netherite Spell Book | VI |
| NanoMuscle, включая advanced chestplate | VI |
| QuarkTech, включая advanced chestplate | VIII |
| Simply Swords из тега `simplyswords:uniques` | VII |
| Winged Tiara в Curios (`botania:flight_tiara`, любая окраска) | VI |

Проверяется каждый серверный тик: закрытая броня, оружие в активной руке и тиара снимаются и возвращаются в свободную ячейку обычного инвентаря. Закрытое оружие не возвращается в выбранную ячейку руки. При полном инвентаре полная запись ItemStack с NBT сохраняется в `ForgeData.PlayerPersisted.expedition_gear_reserve`; освобождение ячейки запускает возврат. Ничего не выбрасывается. Ношение вещей в рюкзаке разрешено, броня в руке разрешена. Выбор закрытого оружия означает попытку активного использования и запускает перенос.

Также отменяются нанесение урона закрытым оружием, ПКМ закрытой вещи и раннее надевание тиары через `CurioEquipEvent` с результатом DENY. Однотиковые пассивные эффекты и дополнительные пути сторонних модов не считаются полностью закрытыми. Данные резерва сериализуются вместе с игроком; полный цикл смерти/возрождения и отключения реального клиента не испытан.

## Проверка и открытые задачи

Проверочный dedicated server использует отдельную копию тестового мира, без изменения пользовательских миров. Проверены нативные реестры действий Hex и 122 компонента M&A; границы разрешения Forge event, сохранение настроек Hex, нативный отказ раннего полёта и Curios, перенос при полном инвентаре и точное сохранение NBT. Подробный результат — в release note.

Рецепты 0.12–0.13 сохраняют связи Create/Botania/GT/RS и боссовых материалов; 0.14 добавляет ограничения использования. Квестовые описания школ и ролей обновлены, идентификаторы и определения задач сохранены: 22 главы / 185 записей / 220 задач.

Остаются: Hazen и прочая отдельная экипировка, награды SLB/Cataclysm, навыки Sword Soaring, сравнение урона/лечения/контроля, настоящие бои девяти боссов, клиентская проверка и финальный промышленный проект. Прежняя проблема памяти при генерации нового мира не устранена.

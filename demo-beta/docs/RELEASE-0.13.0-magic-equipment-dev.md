# 0.13.0-magic-equipment-dev

Добавлена первая серверная проверка применения магии Iron’s и общие материалы для боевой экипировки. Найденный или переданный свиток больше не открывает выбранные поздние способности раньше этапа. HP/урон боссов не менялись.

## Поведение

- Forge SpellPreCastEvent отменяется на сервере до initiateCast: Rare требует III, Epic VI, Legendary VII. Редкость определяется для текущего уровня заклинания по конфигурации мода. Обработка действует для игроков, включая creative, а не для магии мобов.
- Восемь отдельных эффектов имеют минимальные этапы: Angel Wing/Teleport VII; Greater Heal/Healing Circle/Raise Dead/Summon Polar Bear III; Summon Vex/Raise Hell VI. Если редкость уровня требует более поздний этап, выбирается более поздний.
- Семь новых компонентов соединяют обычный ресурс с повторяемым материалом кампании. Четыре террастальные части брони и два алмаза diamond spell book используют материал Lothric; 15 незеритовых форм Simply Swords — рунический незерит Lothric. Четыре netherite mage armour и netherite spell book используют усиленный незерит Cinder. Основы, шаблоны, руны и остальные составляющие сохранены.
- Три катализатора варки rare/epic/legendary ink требуют материалы Lothric/Cinder/Nightlord. Сохраняются ступени жидкости 1000→250 mB и штатный разлив Create. Common/uncommon ink не изменены. Редкие свитки/чернила в луте не удаляются: они остаются запасом для будущего этапа.
- Добавлены семь необязательных квестов боевых ролей. Всего 22 главы / 185 записей / 220 задач; прежние 178 task sets сохранены, нет новых ручных галочек или бесплатных наград. Защита не является обязательным условием босса.

[Подробная схема, состав компонентов и ограничения](MAGIC-EQUIPMENT.md).

## Верификация

Прошли 9 тестов установщика и 3 контракта прогрессии; граф квестов без циклов, исторические ID/задачи сохранены, генерация детерминирована. Состав/версии/хеши внешних модов и save_schema=4 не изменены.

Runtime выполняется в отдельной instances/magic-equipment-0.13-check на копии QA-мира 0.12, localhost25583, Java17/Forge47.4.10. Обновления рецептов проверяются по содержимому JSON, а не по наличию replaceInput. Для Botania armor_upgrade, smithing additions, shaped book keys и brewing input изменяются точные поля с сохранением остальных данных.

При тестировании обнаружены реальные API-особенности: ресурс полёта называется angel_wing; ForgeEvents доступен только startup; до штатной OnDatapackSync Iron’s возвращает fallback maxLevel1/common. Предыдущие проверки редкости на пустом сервере до синхронизации не являются подтверждением. Окончательный тест вызывает штатную синхронизацию в QA-мире и проверяет настоящие уровни/редкости 111 заклинаний.

startup-013-boundaries.log: 28 проверок рецептов + 2186 проверок применения/этапов, 111 заклинаний, 0 ошибок событий, 0 failed recipes (38 added / 56 removed / 222 modified), MAGIC_AUDIT_COMPLETE. События каста создаются с FakePlayer и публикуются в настоящий Forge event bus. Проверяются книга/свиток/оружие, точная стадия, запрет перед ней и разрешение на ней; это тест обработчика, а не клиентский бой или доказательство корректных затрат маны при реальном касте. QA-скрипт не распространяется.

Инвентаризация COMBAT-SOURCES.json: 4005 JSON-рецептов и 1742 JSON-таблицы лута в девяти зафиксированных модах; JAR проверяются SHA256. Java-генераторы GT, торговля, награды mcfunction и фактические эффекты требуют дополнительного анализа. В bootstrap включены каталог ссылок и его генератор, но не JAR/миры/чужие функции.

## Открытые задачи

M&A/Hex, Hazen-экипировка, применение полученной вне крафта брони/оружия, NanoMuscle/QuarkTech, навыки и уникальные награды ещё не приведены полностью к общим этапам. Не проверены графический клиент, настоящие бои и взаимодействия лечения/контроля/полёта. Рецепты и pre-cast не объявляются полным антиобходом. OOM генерации нового мира и финальный промышленный проект остаются открытыми.

Нужен полный перезапуск сервера и клиентов. Схема сохранений прежняя; старые вещи/квесты/флаги не удаляются. Тестовые флаги нельзя переносить в основной мир. Bootstrap собран локально; публикация GitHub Releases не выполнялась.

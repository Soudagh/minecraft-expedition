# Магия и боевые роли · 0.13

Продолжение реализовано в [0.14: школы и найденная экипировка](SCHOOL-EQUIPMENT-GATES.md). Ниже сохранено описание первого этапа 0.13; его список открытых задач исторический.

Первая реализация ограничений магии и экипировки для полной сборки. Введены семь общих компонентов, 28 изменённых рецептов и серверная проверка начала каста Iron’s. HP/урон боссов пока не меняются: для этого нужны реальные бои доступными комплектами.

## Каст Iron’s

Проверяется SpellPreCastEvent на сервере, до initiateCast в AbstractSpell. Ограничение не зависит от способа получения свитка: книга, свиток и оружие проходят один обработчик. Мобы не являются PlayerEvent и продолжают использовать собственную магию.

| Способность | Минимальный общий этап |
|---|---:|
| Common/Uncommon без отдельного ограничения | 0 |
| Rare | III · Lothric |
| Epic | VI · Soul of Cinder |
| Legendary | VII · Nightlord |
| Greater Heal, Healing Circle, Raise Dead, Summon Polar Bear | III, либо выше по редкости текущего уровня |
| Summon Vex, Raise Hell | VI, либо выше по редкости текущего уровня |
| Angel Wing, Teleport | VII |

Редкость вычисляется модом для текущего уровня, а не из имени предмета/чернил. Это первоначальный общий потолок мощности; восемь отдельных ограничений выбраны по эффектам. Остальные способности ещё требуют сравнения урона, лечения и контроля. Legendary не считается автоматически равноценной силой во всех школах. Проверяются и creative-игроки; административное изменение флагов остаётся административным доступом.

Лут со свитками не уничтожается: предмет можно сохранить до открытия. Катализаторы варки ограничивают производство, а событие каста ограничивает использование. Базовое Heal и обычные слабые атакующие заклинания не получили отдельного запрета — роль поддержки доступна рано.

Важный нюанс тестирования: до OnDatapackSync конфигурация Iron’s возвращает fallback maxLevel=1/minRarity=COMMON. Проверка пустого dedicated server без синхронизации не подтверждает ограничения редкости. QA явно вызывает штатную синхронизацию в отдельном тестовом мире; в обычной игре мод выполняет её при входе игрока.

## Материалы и рецепты

| Новый компонент | Состав | Использование |
|---|---|---|
| Настроенная террасталь | 1 terrassteel ingot + 1 material_lothric | Четыре части террастальной брони, по 3 настроенных слитка; манастальная основа, сезонные руны и веточки сохраняются |
| Настроенный алмаз | 1 diamond + 1 material_lothric | Два алмаза книги Iron’s Diamond; ткань, hogskin и зачарованная книга сохраняются |
| Рунический незерит | 1 netherite ingot + 1 material_lothric | Все 15 незеритовых форм Simply Swords; алмазная основа и шаблон сохраняются |
| Усиленный незерит | 1 netherite ingot + 1 material_cinder | Четыре части netherite mage armour и netherite spell book; остальные входы сохраняются |
| Катализатор редких чернил | 1 iron ingot + 1 material_lothric | 1000 mB uncommon → 250 mB rare ink |
| Катализатор эпических чернил | 1 gold ingot + 1 material_cinder | 1000 mB rare → 250 mB epic ink |
| Катализатор легендарных чернил | 1 amethyst shard + 1 material_nightlord | 1000 mB epic → 250 mB legendary ink |

Новые компоненты не добавлены в общие теги diamond/netherite/terrasteel: их нельзя вместо обычного ресурса вставлять в другие рецепты и неожиданно обходить ограничения. Террастальные слитки и производственные возможности Botania сами по себе не закрыты — изменена броня, а не вся школа. Базовая магическая экипировка сохраняется.

Котёл сохраняет объёмы и ступени чернил. Create filling/emptying остаются штатной логистикой жидкости; разлив не повышает её редкость. Переработка найденных свитков и торговля могут давать чернила иначе — ранний каст всё равно проверяется.

## Квесты и роли

Новая необязательная глава «Боевые роли» содержит семь целей: террастальная защита, пример рунического оружия, книга заклинателя, поздняя магическая защита и три катализатора чернил. Всего 22 главы / 185 записей / 220 задач. Ни одна цель брони не стала условием победы или промышленного открытия. Предметные задачи не изымают вещи и не доказывают использование магии.

## Инвентаризация источников

Каталог [COMBAT-SOURCES.json](COMBAT-SOURCES.json) получен из зафиксированных JAR с проверкой SHA256. Содержит ID рецептов/loot tables и прямые ссылки на item/tag/functions/types. Это исходные файлы до скриптов, не доказательство достижимости в мире. Динамические рецепты GT и способности Sword Soaring заданы Java-кодом: ноль JSON-рецептов не означает отсутствие содержания.

## Что остаётся открытым

- M&A SpellCastEvent имеет caster/context/definition, Hex исполняет действия через собственный casting API. Ограничения этих школ по общим этапам ещё не внедрены; их полёт, телепорт и добыча могут обходить нынешнюю модель.
- Hazen в watered-down edition даёт отдельную экипировку; состав реестра Iron’s проверяется runtime. Добавленные предметы не считаются автоматически ограниченными только из-за зависимости от Iron’s.
- Рецепты брони/оружия не запрещают ношение найденной или переданной вещи. NanoMuscle/QuarkTech, уникальные награды SLB/Cataclysm, навыки Sword Soaring и эффекты Simply Swords ещё требуют настройки. Прежний запрет unique Simply Swords в CHEST loot сохранён; другие источники не заявлены закрытыми.
- Призванные существа, самописные вызовы onCast и длительные уже активные эффекты не проверяются повторно этим pre-cast. Есть ли такие обходы в составе, нужно установить игровыми испытаниями.
- Нет результатов настоящих боёв/сравнения комплектов/клиентского GUI. Открыта прежняя проблема OOM генерации нового мира. Финальный промышленный проект не реализован.

Нужен полный перезапуск клиента и сервера: Forge-слушатель и новые предметы регистрируются при startup. Старые предметы/квесты/флаги не удаляются.

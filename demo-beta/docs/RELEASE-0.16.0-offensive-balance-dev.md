# 0.16.0-offensive-balance-dev · локальная версия

Уменьшен магический вклад руны Imbued Simply Swords: коэффициент 2 → 1. Её усиление связывает общую магическую силу и школу Ender; базовые значения обычной/Greater-руны сохраняются. Цель — снизить рост дополнительного урона гибридного комплекта, сохранив саму синергию.

[Формулы, замеры и границы проверки](OFFENSIVE-BALANCE.md).

Нативный стенд подтвердил 56 сопоставленных попаданий до/после и ещё четыре сочетания общей силы ×2 / Ender ×2. Финальный запуск: 648 успешных проверок. Попадания Magic Missile, Firebolt и первой цели Chain Lightning сохранились; совпали все параметры 111 заклинаний / 777 уровней и бонусы атаки/скорости 60 предметов Simply Swords. Коэффициент Imbued — единственное изменение в конфиге рун. Chance, остальные способности и общие этапы сохранены.

При общей силе 4 расчётное значение обычной Imbued меняется 17.36 → 8.68, Greater — 17.36 → 10. Без магических бонусов остаётся 6/10. Это выход функции способности, не DPS игрока. Настоящие попадания измерены с неигровым заклинателем и нативными множителями для мобов; подробности приведены в отчёте.

Сохранены версии и хеши 71 клиентского / 64 серверных JAR, схема сохранений 4 и 22 главы / 185 квестов / 220 задач. Уточнено описание оружия в квесте боевой роли. Подготовлены исходные параметры Sword Soaring для следующего прохода; сами навыки пока не перенастроены.

12 тестов установщика/прогрессии прошли. Валидатор подтвердил сохранение всех 185 прежних квестов / 220 задач и отсутствие циклов. Тестовый сервер сохранил мир и остановлен; ошибок событий и неуспешных рецептов нет.

Это локальная рабочая версия. Последний опубликованный [GitHub prerelease — 0.15](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.15.0-combat-sustain-dev). Probe включён как инструмент и не исполняется в обычной сборке. Для применения конфига требуется полный перезапуск. Клиент, реальные бои вчетвером, все комбинации и новый долгосрочный мир пока не подтверждены.

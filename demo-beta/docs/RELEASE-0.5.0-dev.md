# 0.5.0-dev — постройки и конкретные цели квестов

Добавлен Explorify 1.6.5: таверны, лагеря, руины, башни, поселения и мавзолеи. Black Spiral и End Shipwreck временно отключены; в таверне убрана комната с лутом древнего города. Остальной лут ещё не полностью сбалансирован. Новые структуры появляются на новой территории, существующий мир не пересоздаётся.

16 ручных упражнений заменены новыми проверяемыми задачами: 13 предметных целей и 3 посещения конкретных структур. Примеры: 16 точных механизмов; по 2 руны каждой стихии; 2 фокуса Hex; линза и 4 малых свитка; молот и резец рунописца; 64 хлеба и 64 факела; таверна, мавзолей и Катакомбы Картуса.

Предметы не изымаются. Задание проверяет наличие и количество, а не факт крафта/автоматизации. Структурное задание проверяет вход на её территорию, не зачистку. Автоматический учёт побед SLB и ресурсные замки пока не добавлены.

Все старые ID задач и их определения сохранены. 16 прежних ручных упражнений перенесены в необязательный архив, их галочки не засчитываются за новые задачи. Теперь 9 глав / 99 записей с учётом архива; рост счётчика не означает дополнительный объём обязательного гринда. Для старых предметных квестов завершения сохранены, новые предметные/структурные цели имеют собственные ID.

База: 49 внешних модов, оба визуальных профиля дают 51 JAR и шейдер. Автовключение шейдеров из 0.4.1 сохранено. Боевые анимационные моды не добавлялись: [найденные кандидаты](STRUCTURES-AND-COMBAT.md).

## Проверки и ограничения

- Четыре теста установщика прошли. Все прежние задачи сравнены с 0.4.1, отсутствующие/повторные ID и циклы зависимостей не найдены.
- На отдельной копии прежнего тестового мира запущен Forge 47.4.10 / Java 17. FTB загрузил 9 глав и 99 записей, 64 уникальных предмета целей существуют в реестре. Ошибок скриптов KubeJS не обнаружено.
- Найдены таверна и мавзолей через `/locate`; это проверка регистрации и поиска, не визуальный осмотр постройки и не проверка зачёта квеста реальным игроком.
- Полное прохождение, фактическое срабатывание заданий с клиентом и сложность/лут построек требуют игрового теста. Сохраняются прежние нефатальные предупреждения модов на сервере.

## Обновление

Схема сохранений 2 сохраняется. Закройте игру/сервер, используйте `--from-instance` со своей текущей папкой, `--stopped` и новую папку назначения. Выбранные ранее визуальные профили наследуются без дополнительных параметров. Старый экземпляр остаётся резервной копией. Перезапуск обязателен, `/reload` не использовать.

# Локальный патч 0.25 для установленной 0.22–0.24

`expedition-0.25.0-kitchen-sustain-dev-balance-patch.zip` включает промышленный баланс 0.23, рецепты/этапы напитков 0.24 и клиентские подсказки 0.25. Одинаково обновите сервер и всех клиентов.

1. Полностью остановите игру и сервер. Сделайте резервную копию экземпляра.
2. Объедините папку `kubejs` из архива с игровой папкой `kubejs`, заменив одноимённые файлы. Собственные правки объедините вручную.
3. Полностью перезапустите игру и сервер. При обновлении с 0.22/0.23 новые настои требуют startup-регистрации, одного `/reload` недостаточно.
4. В инвентаре/JEI проверьте подсказки Saccharine Rum, Red Rum и двух настоев. Для лечебного рома указан расход насыщения; для напитков указаны этапы II/III.

Подсказки — единственная новая игровая правка относительно 0.24. Коэффициенты еды и заклинаний сохранены. Патч кумулятивный; для обновления с 0.22/0.23 также действуют [промышленные изменения](INDUSTRY-BALANCE.md) и [рецепты напитков](KITCHEN-BALANCE.md). Подробнее: [еда и лечение](FOOD-SUSTAIN.md).

Для полного отката восстановите резервную копию. При откате с новыми настоями их сохранность без зарегистрированных предметов не гарантируется. Версия локальная, на GitHub не опубликована.

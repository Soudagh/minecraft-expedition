# 0.11.0-boss-progression-dev

Введена серверная основа баланса всей сборки: девять общих боссовых открытий, девять воспроизводимых материалов и ограничения производства корпусов GT LV–UV. Это рабочая версия для испытаний, не завершённое прохождение.

## Поведение

- Победы сохраняются в мире; ступень продвигается только по непрерывной цепочке. Победа вне порядка остаётся в ожидании, а не пропускает предыдущие этапы.
- SLB получает шесть вставок в финальные callbacks при установке из проверенного JAR; Graveyard/EEEAB используют серверные события урона и смерти. Есть проверки участия survival-игрока, фаз и отсутствия mob_battle. /kill не открывает native-боссов.
- Схема в основной руке + ПКМ по кузнечному столу выпускает четыре единицы материала из сырья. Схема сохраняется; закрытая или неполная партия ничего не тратит. Повторное убийство не нужно.
- Корпуса LV/MV требуют этап V, HV/EV — VI, IV — VII, LuV — VIII, ZPM/UV — IX. Рецепты верстака и сборщика сохраняют исходные составляющие через новый компонент. Размещение и ручное открытие перечисленных машин также ограничены сервером.
- Добавлена кампания из 18 записей. Всего 21 глава / 178 записей / 213 задач. Сохранены прежние 160 quest ID и определения задач версии 0.10; новые зависимости не переименовывают старые цели. Нет нового финала за получение корпуса.

[Состав партий и точные границы ограничений](BOSS-PROGRESSION.md).

## Проверки

Статическая проверка: уникальные ID, существующие зависимости, отсутствие циклов; сохранены 99 исторических квестов / 108 определений задач HEAD и отдельно 160 квестов 0.10. Прошли 3 контракта прогрессии и 9 тестов установщика. Версии, хеши и состав всех внешних модов не менялись; save_schema=4.

Серверные сценарии выполняются в instances/boss-progression-0.11-check на отдельной копии прежнего QA-мира 0.9. Они используют административные фикстуры, а не объявляют настоящие бои пройденными. startup-011-passed.log: 79 успешных утверждений, 185 зарегистрированных ID, все 17 рецептов корпусов (8 shaped + 9 assembler), девять партий с точным расходом всех входов, повторный выпуск без убийства, закрытая/неполная партия без потерь, проверки фаз и summon+/kill; ошибок ServerEvents.loaded/hurt/death нет, 0 failed recipes (22 added / 51 removed / 192 modified). startup-011-persistence.log подтверждает после полного перезапуска stage=1, Watchers=1, отложенный Annihilator=1, Champion=0; штатные нефатальные предупреждения M&A/client-class и loot из прежней сборки отдельно не исправлялись.

## Оставшаяся работа

Нужны настоящие девять боёв, участие через заклинания/призывы, GUI обработки и размещения, вход офлайн-игроков и прохождение вчетвером. Не закрыты все источники лута/торговли/разборки, магические способности, альтернативный полёт и добыча, NanoMuscle/QuarkTech, поздние HBM и энергетика. Личные условия доступа SLB не преобразованы в командные. Автоматика уже поставленных машин не останавливается этим событием ПКМ. Финальный работающий проект не реализован.

Предыдущий запуск нового мира с 5 ГБ памяти завершился OOM в генерации NBT/структур. Причина остаётся открытой; запуск копии готового QA-мира не доказывает исправление генерации.

## Установка

Нужен полный перезапуск клиентов и сервера. Startup-регистрация предметов несовместима с обновлением через /reload. Обновлять только остановленный экземпляр с отдельной резервной копией; тестовые флаги не переносить в основной мир. Старые прохождения не распознаются автоматически по трофеям или галочкам атласа.

Bootstrap 0.11 собран локально. Публикация в GitHub Releases не выполнялась. Технические имена demo-beta/expedition-demo сохранены для совместимости и не возвращают формат демо.

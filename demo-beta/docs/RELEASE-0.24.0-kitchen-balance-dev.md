# 0.24.0-kitchen-balance-dev — снабжение боевой кухни

Локальная версия, на GitHub не опубликована. Состав JAR, настройки энергии и книга 34/951/1000 сохранены. Включает промышленный баланс 0.23.

Партия Saccharine Rum требует настоя из арбуза и материала Champion; партия Red Rum — настоя из светогриба и материала Lothric. Материал расходуется на 1000 mB, то есть четыре обычные кружки. Оригинальный арбуз/светогриб остаётся в общей стоимости через промежуточный настой, остальные ингредиенты, жидкость, температура, время и выход не изменены. Бочка сохраняет три/четыре входных слота.

Серверное Forge-событие начала использования разрешает Saccharine Rum с общего этапа II, Red Rum — с III. До открытия кружка не расходуется. Обычные блюда и другие напитки сохраняют рецепты и штатные эффекты; общего ограничения всех положительных эффектов нет.

[Подробные изменения кухни и аудит энергетики](KITCHEN-BALANCE.md) · [Обновление 0.22/0.23](UPDATE-0.24.md).

## Проверки и ограничения

18 тестов прошли: 11 установщика, 3 прогрессии, 2 сохранения затрат HBM и 2 кухни. Финальная Forge QA: 299 условий кухни/энергетики, 276 промышленного баланса, 10124 книги; 0 ошибок скриптов/событий и 0 неудачных рецептов. Пакет книги 873418 байт. [Отчёт](KITCHEN-ENERGY-RESULTS-0.24.json). Для мотора используется подтверждённая байткодом формула и текущий конфиг; нативная функция генератора, обмен HBM и Forge-событие употребления проверяются напрямую.

Тесты сохранения нативных расходов HBM и бочки, установщика и прогрессии прошли. QA работает на отдельной копии тестового мира с Forge 47.4.10 и Java 17; проверки рецептов, настоящего Forge-события с FakePlayer и энергетических API не являются прохождением человеком или собранной промышленной линией.

Предстоит измерить реальное сочетание Sweet Heart, питания, магического лечения и Raging в бою, время снабжения команды и энергетику линий с передачами/нагрузками/топливом. Нативные коэффициенты энергии не меняются без найденного воспроизводимого выгодного цикла.

Патч для 0.22/0.23 включает 17 игровых файлов: 13 промышленного баланса и четыре кухни (startup, server script, два JSON-рецепта). Для новых зарегистрированных предметов нужен полный перезапуск и клиентам, и серверу.

# 0.9.0-hbm-qol-preview

HBM, подсказки блока/мода и здоровья, Hazen ’N Stuff, Refined Storage вместо AE2 и ускорение обычных деталей GregTech. Minecraft 1.20.1, Forge 47.4.10, Java 17. Новый мир обязателен; схема сохранений 4.

## Состав

| Jade | 11.13.3+forge | Название блока/мода и числовое HP под прицелом |
| Hazen ’N Stuff | 1.1.2 Watered Down | Дополнение оборудования и магии для Forge 1.20.1 |

71 внешний JAR на клиенте, 64 на сервере. Профиль shaders добавляет Oculus: 72 JAR и ZIP Complementary. Terralith, Tectonic, Lithostitched, Farmer’s Delight и Brewin’ and Chewin’ сохранены.

Удалены AE2, GuideME и GTMThings: GTMThings 1.6.0 объявляет AE2 обязательной зависимостью. Также временно удалён GT-- 1.3.10: после замены состава его интеграция Botania падает с `Registry is already frozen`. Испытания с предварительной инициализацией через KubeJS не исправили проблему; эти экспериментальные скрипты в архив не входят. Основной GTCEu 7.5.3, LowDragLib и Solar Expansion остаются.

Источники файлов: [HBM Modernized](https://modrinth.com/mod/hbms-nuclear-tech-modernized/version/rEJAJjEN), [Hazen 1.1.2](https://www.curseforge.com/minecraft/mc-mods/hazen-n-stuff/files/7501581), [GTBC SpellLib](https://www.curseforge.com/minecraft/mc-mods/gtbcs-spelllib/files/8824662), [Refined Storage](https://modrinth.com/mod/refined-storage/version/ZITLFjjf). Точные URL, размеры и SHA-256 зафиксированы в mods.lock.json.

## Изменения игры

- Jade устанавливается на обе стороны. Клиент получает начальные настройки названия блока, мода и числового здоровья. Это подсказка под прицелом, не полоски над всеми мобами. Настройки можно менять; установщик их сохраняет.
- В общем каталоге JEI скрыты варианты Chipped. Видны alchemy bench, botanist workbench, carpenter’s table, glassblower, loom table, mason table и tinkering table. Декор выбирается через эти столы; блоки, рецепты и постройки не удалены. Скрытие не уменьшает число зарегистрированных блоков или расход памяти.
- У 172 рецептов обычных деталей GT длительность делится на 2 с округлением вверх до целого тика. Это bender, wiremill, lathe и cutter, EU/t не выше 128, один предметный выход. Разрешённые материалы: железо, медь, олово, бронза, сталь, свинец, серебро, золото, красный сплав. Выходы: обычные пластины, стержни, длинные стержни, болты, винты, кольца, фольга, одиночная и тонкая проволока. Фактически применённый список см. GT-QOL-0.9-RECIPES.md.
- Расход сырья, выходы, жидкости, EU/t, инструменты, схемы конфигурации и условия сохранены. Энергия на операцию уменьшается вместе с временем. Сборщики, химические цепочки, новые схемы, добыча, генераторы, ядерное топливо и поздние материалы не ускорены.
- Железная/свинцовая наковальня и пресс HBM теперь требуют корпуса MV; пресс также требует поршень MV и настроенное ядро. Это привязывает старт этой ветки к GregTech. Контроллер Refined Storage вместо собственного корпуса требует корпус LV, который уже связан с магическим настроенным ядром.
- Рецепты гранат, ракет и сборщика ракет HBM, а также их сундуковый/мобовый лут отключены в соответствии с прежней политикой ограничения оружия. Творческий доступ остаётся.
- Исправлен ошибочный тег размещаемых картин HBM (`hbm_m:bober1`). Сохранены 26 ванильных картин и картина Epic Fight; отсутствующая картина HBM стала необязательной.

## Установка в Legacy — Windows

Скачайте ZIP в Assets этого релиза, распакуйте и откройте PowerShell в папке expedition-demo. Python 3.10+, Java 17. Папку назначения заранее не создавайте:

```powershell
py tools/install.py --side client --visuals shaders --destination "$env:USERPROFILE\Games\Expedition-0.9"
```

Дождитесь `Prepared:`. В Legacy укажите этот полный путь как игровую директорию, выберите «Не использовать отдельные папки», Java 17 и Minecraft 1.20.1 с точным Forge 47.4.10. Для клиента с шейдерами начните с 8192 МБ при наличии 16 ГБ ОЗУ. Создайте новый мир. Пошаговые действия также находятся в START-HERE.txt и [INSTALL-LEGACY-WINDOWS.md](INSTALL-LEGACY-WINDOWS.md).

Если возникает SSL-ошибка, выполните `py -m pip install --upgrade truststore` и повторите ту же команду. Проверки HTTPS и SHA-256 включены. Установщик показывает URL загрузки и использует уже проверенные файлы кеша.

Сервер устанавливается отдельно, без профиля shaders:

```powershell
py tools/install.py --side server --destination "E:\Minecraft\Expedition-0.9-server"
```

Затем установите Forge 47.4.10 Server в эту папку, ознакомьтесь с EULA и настройте сервер. Все игроки должны установить именно 0.9.0.

Не используйте `--from-instance` для 0.8 и прежних версий и не переносите их saves вручную. Удаление AE2/GTMThings/GT-- меняет блоки и предметы; старые сохранения и инвентари могут потерять содержимое. Прежняя установка остаётся отдельно для отката.

## Проверки и ограничения

Проверены загрузки и SHA-256 всего состава, установка клиента с shaders и сервера, 9 тестов установщика, создание нового мира и повторный серверный запуск с сохранением/штатной остановкой. Независимый аудит 2658 рецептов четырёх GT-машин показал: у 172 меняется только длительность, 2486 остались без изменений. Примеры: медная проволока 63 → 32 тика, стальная пластина 56 → 28 тиков. Финальный запуск: рецепты без ошибок разбора. Книга прежняя: 9 глав / 99 записей.

Графический клиент, положение Jade относительно Epic Fight, удобство JEI, бои Hazen и полное выживание на Windows пока не проверены. Старые нефатальные предупреждения M&A и обращения библиотек к клиентским классам на сервере остаются. Это preview: общие серверные открытия эпох по боссам, полная проверка обходов FE/EU и темпа прохождения ещё не реализованы. Ускорение деталей и статические требования к корпусам не гарантируют, что одиночный игрок не обгонит команду. HBM alpha содержит лишь часть оригинала; наличие всех реакторов и цепочек оригинального HBM не обещается.

Архив содержит исходники, конфиги, книгу и установщик. Сторонние JAR скачиваются с площадок авторов; это не готовый архив mods. Исходные установки и пользовательские сохранения не изменялись.

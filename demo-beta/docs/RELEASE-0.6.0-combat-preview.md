# 0.6.0-combat-preview — Sword Soaring и Epic Fight

Выбранный Sword Soaring добавлен вместе с обязательными Epic Fight и Invincible Lib. Better Combat заменён. Combat Roll сохранён ради трёх существующих зачарований. First-person Model исключается установщиком из новой копии; шейдеры и их настройки сохраняются.

51 основной внешний JAR, с профилем shaders — 52 JAR и ZIP Complementary. Версии: Epic Fight20.14.17, Sword Soaring20.14.2.8, Invincible Lib20.14.8.2. Все Forge1.20.1. Для75обычных/рунических предметов Simply Swords добавлены стандартные боевые типы; уникальное оружие не считается полностью адаптированным.

## Как проверить

Создайте отдельный творческий мир. В настройках управления включите действие Toggle Battle/Mining Mode из Epic Fight Combat. Возьмите Vatansever (`/give @s sword_soaring:vatansever`), переключитесь на F5 и прочитайте комбинации в подсказке Shift. Подробная инструкция и команда обновления — [SWORD-SOARING.md](SWORD-SOARING.md).

Это проба новой боевой системы. Сильные умения и полёт ещё не встроены в ресурсные этапы, дешёвый рецепт/стартовая выдача Vatansever не добавлены. Установка не открывает все навыки автоматически. Не переносите творческие тестовые предметы в основное прохождение.

## Проверка

- Пять тестов установщика прошли, включая переход с Better Combat/First-person Model при сохранении мира и Combat Roll. Старые файлы удаляются только в новой копии; исходник сохраняется.
- Окончательная копия прежнего тестового мира загрузилась на Forge47.4.10/Java17: 9глав/99записей квестов. Ошибок загрузки скриптов и файлов способностей оружия не обнаружено.
- Первый эксперимент без Combat Roll показал неизвестные enchantment mappings. Он отброшен, окончательная копия подготовлена заново из0.5 с Combat Roll. В ней остаётся ожидаемое сообщение о старых звуках Better Combat, а не об удалённых зачарованиях.
- Клиентский экземпляр установлен с переносом графического профиля; он содержит Epic Fight/Sword Soaring/библиотеку и шейдеры, без Better Combat и First-person Model.
- Графический клиент, эффекты, совместимость брони/магии и бой с боссами НЕ проверены. Combat Roll и Epic Fight имеют разные уклонения; их взаимодействие требует проверки. Сохраняются старые нефатальные серверные предупреждения модов.

Схема сохранений2. Обновляйте отдельный сервер тоже. Для отката используйте нетронутую старую папку, не открывайте новый мир старым составом модов.

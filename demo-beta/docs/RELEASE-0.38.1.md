# Экспедиция 0.38.1 · финальная подготовка Draconic

Draconic Evolution открывается после Cataclysm, всех девяти основных побед и Lady Luna. Хаотическая ступень — после Chaos Guardian.

Все 28 fusion-рецептов инструментов, нагрудников, конденсаторов и посохов дополнительно расходуют компоненты других модов. Wyvern: ZPM-мотор GregTech, слиток Gaia Botania, порошок шрабидия HBM. Draconic: UV-мотор, Gaia и шрабидий. Chaotic: по два каждого. Сохранены прежние катализаторы, материалы, уровни инжекторов и энергия. Оба пути Chaotic Staff учтены.

44 статических теста и 254 нативных условия по 28 рецептам прошли; 0 failed recipes. Полная живая fusion-станция и время добычи четверыми ещё требуют игрового прогона. Подробности: docs/DRACONIC-ENDGAME.md.

Состав модов и схема сохранений 4 сохранены. Перед обновлением остановите сервер и сделайте резервную копию. Нужны обновление клиента и сервера и перезапуск. Установщик создаёт новую копию клиента; для существующей 0.38 доступен небольшой патч, распаковываемый в корень экземпляра. Он содержит только 28 JSON рецептов, главу финальных квестов и mods.lock.json; мир, настройки сервера, JAR и данные игроков не включены.

Полные bootstrap/server ZIP и патч имеют отдельные SHA-256. Установка полной версии: docs/INSTALL-0.38.md.

# Expedition 0.7.0-industry-preview

Тестовая версия для знакомства с техническими аддонами. Это ещё не готовый экспертный баланс: боссовые этапы, стоимость беспроводной энергии, солнечных панелей, AE2 и мост FE/EU требуют отдельной настройки. Новых квестов в этом выпуске нет; прежние 9 глав / 99 записей сохранены.

## Добавлено

| Мод | Версия | Назначение |
|---|---|---|
| Create: Connected | 1.2.3 | Управление механизмами и логистика |
| Create: Copycats+ | 3.0.10 | Оформление построек и механизмов |
| Create Crafts & Additions | 1.3.3 | Электромоторы, генераторы, FE |
| Create: Enchantment Industry | 2.5.4 | Производство зачарований и ремонт |
| Create: Diesel Generators | 1.3.12 | Двигатели и топливное производство |
| GT-- | 1.3.10 | Дополнительные машины и поздние процессы |
| GTMThings | 1.6.0 | Беспроводная инфраструктура GregTech |
| GregTech Solar Expansion | 0.2.3 | Солнечная энергетика |

Зависимости: Create: Dragons Plus 1.11.9, LowDragLib 1.0.52.a, Applied Energistics 2 15.4.11 и GuideME 20.1.15. AE2 обязателен для выбранного GTMThings. В клиентской базе 63 внешних JAR; с профилем shaders — 64 JAR и ZIP Complementary. Встроенные библиотеки увеличивают число модов в меню игры.

## Изменения для совместимости и баланса

- Рецепты химического распылителя, его огненной версии и турели Diesel Generators удалены; предметы также исключены из сундукового/мобового лута. Творческий режим и команды остаются средствами тестирования.
- Enchantment Industry: расширение предельного уровня чар установлено в 0 для Blaze Enchanter/Forger; игнорирование несовместимости чар выключено. Это не ограничение ношения экипировки по XP. Конфигурация в defaultconfigs применяется при первом создании конфигурации мода в мире; существующую вручную настроенную конфигурацию CEI нужно проверить отдельно.
- GT--: enableHarderPlatinumLine и enableHarderNaquadahLine выключены из-за конфликтов с GTCEu 7.5.3. Машины аддона оставлены.
- Удалён генерируемый рецепт gtceu:shapeless/centrifuged_ore_to_dust_neutronium: он содержал пустой ингредиент. Бесплатного заменяющего рецепта нет.
- Сохраняется предупреждение GT о дублирующейся регистрации bend_lanthanum_plate_to_dense_plate. Полная проходимость новых промышленных цепочек пока не подтверждена.
- Моды физики в этот релиз не входят: результаты проверки в CLOCKWORK.md.

## Обновление в Windows CMD

Закройте Minecraft и лаунчер. Распакуйте этот архив и откройте CMD внутри expedition-demo. Исходный путь должен указывать на вашу рабочую версию; папка назначения НЕ должна существовать.

```bat
py tools/install.py --side client --from-instance "E:\Minecraft\Expedition-0.6-combat" --stopped --destination "E:\Minecraft\Expedition-0.7"
```

После Prepared выберите E:\Minecraft\Expedition-0.7 как папку игры в лаунчере, Minecraft 1.20.1 + Forge, Java 17. Проверочная версия Forge 47.4.10. Визуальные профили наследуются; для явного включения добавьте --visuals shaders.

Если рабочая папка называется иначе (например Expedition-0.5), замените только --from-instance. Не создавайте папку назначения заранее и не открывайте её в лаунчере во время установки. Сервер обновляйте тем же архивом с --side server и своими путями, после полной остановки.

Схема сохранений остаётся 2. Установщик копирует мир, прогресс и настройки в новую папку, исходную не удаляет. Откат — запуск исходной папки; новый мир после игры с аддонами не переносите обратно в старую сборку удалением JAR.

## Проверка

Пять тестов установщика пройдены. Проверены установка клиентской копии с наследованием shaders и запуск отдельного Forge-сервера с копией мира 0.6. Проверка серверных скриптов и рецептов, загрузка 9 глав / 99 квестов, сохранение $demo=1. Полный графический клиент, шейдеры, интерфейсы новых машин и прохождение цепочек с четырьмя игроками ещё не проверены.

Для первого знакомства используйте отдельный творческий мир. Проверьте меню модов, JEI, механизмы Connected, Copycats, генератор Crafts & Additions, двигатель Diesel Generators и терминал AE2. Не считайте успешный запуск доказательством завершённого баланса.

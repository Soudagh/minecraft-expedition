# Локальный патч 0.24 для установленной 0.22 или 0.23

`expedition-0.24.0-kitchen-balance-dev-balance-patch.zip` включает промышленный баланс 0.23 и два новых рецепта напитков 0.24. Моды и книга не меняются. Нужно одинаковое обновление всех клиентов и сервера.

1. Полностью остановите игру и сервер, дождитесь выхода Java.
2. Сделайте резервную копию экземпляра.
3. Объедините папку `kubejs` из архива с игровой папкой `kubejs`, заменив одноимённые файлы. Собственные правки сначала объедините вручную.
4. Полностью запустите игру и сервер: `/reload` не регистрирует новые предметы.
5. Для двух напитков добавьте изготовление настоя и обновите шаблоны. Для машин HBM подготовьте корпуса по изменениям 0.23.

[Кухня и энергетика](KITCHEN-BALANCE.md) · [Промышленный баланс 0.23](INDUSTRY-BALANCE.md).

Для полного отката восстановите резервную копию экземпляра. Патч содержит новые зарегистрированные предметы, поэтому нельзя обещать сохранность новых настоев при простом удалении их startup-скрипта. Версия локальная, на GitHub ещё не опубликована.

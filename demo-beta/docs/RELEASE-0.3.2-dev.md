# 0.3.2-dev — исправление вылета карты

Подтверждённая причина из клиентского лога: GregTech 7.5.3 интегрируется с новой библиотекой Xaero, а World Map 1.38.8 её не содержит. Возникал `ClassMetadataNotFoundException: xaero.lib.client.gui.widget.Tooltip`.

Заменены две клиентские карты на Xaero’s Minimap 26.6.0 и World Map 1.47.0. Обе содержат XaeroLib 1.7.3; отсутствовавший класс проверен в JAR. Остальные 46 модов сохранены. NEA и боевые анимации остаются. Полный клиентский запуск после замены здесь не выполнен, нужен повторный запуск у пользователя.

Новая мини-карта — обычная, не Fair-Play. Для прежнего режима исследования отключите радар существ и режим пещер в настройках карты; автоматическая настройка этих ограничений пока не внедрена.

## Обновление

Закройте игру/лаунчер. Из новой распакованной папки сборки:

```bat
py tools/install.py --side client --from-instance "E:\Minecraft\Expedition-0.3.1-new" --stopped --destination "E:\Minecraft\Expedition-0.3.2"
```

Назначение должно быть новой папкой. Мир, прогресс и настройки копируются; источник сохраняется. Выберите новую игровую папку в лаунчере. Сервер ради этого исправления обновлять не требуется.

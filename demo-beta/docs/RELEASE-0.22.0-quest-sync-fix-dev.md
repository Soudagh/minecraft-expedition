# 0.22.0-quest-sync-fix-dev

Исправлена подтверждённая причина ошибки «Неверные данные игрока» при входе в одиночный мир: книга FTB Quests 0.21 превышала лимит пакета 1 МиБ. Общие повторяющиеся правила собраны во вступлениях глав; повторная практика использует инструкции предыдущего предметного задания. Уникальные инструкции, критерии и диагностика сохранены.

Сохранены 34 главы / 951 квест / 1000 задач, все ID, определения задач, зависимости, позиции и фиксированные значки. HBM остаётся 12 глав / 238 карточек. Состав модов и рецепты не менялись.

Проверки: 29 автоматических тестов; валидатор исторических 951 квеста / 1000 задач; 10 124 нативных условия книги, 506 предметов и 1316 зависимостей. Исходный `SyncQuestsMessage.toPacket()` воспроизводит превышение лимита; исправленный создаёт пакет **873 418 / 1 048 576 байт**, запас 175 158 байт. [Отчёт пакета](QUEST-SYNC-RESULTS-0.22.json), [отчёт книги](QUEST-BOOK-RESULTS-0.22.json).

Добавлены бюджет текстов генератора, проверка сохранения учебного содержания и отдельный QA-пробник реального сетевого пакета с бюджетом 950 000 байт. Пробник не включён в рабочие scripts сборки.

[Как обновить установленную 0.21](UPDATE-0.22.md). Патч содержит книгу без сторонних JAR, миров и личных логов. Графический клиент и перенос командного прогресса ещё не проверены.

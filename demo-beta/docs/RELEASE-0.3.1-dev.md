# 0.3.1-dev — карта и анимации персонажа

Добавлены клиентские Xaero’s World Map 1.38.8, Xaero’s Minimap Fair-Play 24.2.0 и Not Enough Animations 1.12.6. Всего 48 модов. Мини-карта без радара существ и карты пещер; анимации еды, питья, лазания и других действий видны от третьего лица (F5). Карта мира по умолчанию M; при конфликте клавиш назначьте другую в управлении.

Предыдущие 45 модов, серверный состав, квесты и схема сохранений 2 не менялись. Проверены хеши, обязательные зависимости в JAR, установка клиента и исключение новых модов из серверного набора. Визуальный тест совместимости NEA с Better Combat, Combat Roll и магией ещё нужен; полноценный запуск клиента этой версии здесь не проверен. Ограничения баланса 0.3 сохраняются.

## Обновление

Полностью закройте игру. Из новой распакованной папки сборки выполните (путь источника замените на свой):

```bat
py tools/install.py --side client --from-instance "E:\Minecraft\Expedition-0.3" --stopped --destination "E:\Minecraft\Expedition-0.3.1"
```

Можно обновляться и с 0.2, указав её папку источником. Папка назначения должна быть новой. Установщик сохраняет исходный экземпляр и копирует мир, прогресс, настройки и данные карт; укажите новую папку в лаунчере. Forge 47.4.10, Java 17. Сервер обновлять ради этих трёх дополнений не требуется.

Скачивайте bootstrap ZIP из Assets. Это загрузчик, не архив готовых JAR; необходим Python 3.10+ и интернет. Моды и исправления Souls like Bosses установит скрипт.

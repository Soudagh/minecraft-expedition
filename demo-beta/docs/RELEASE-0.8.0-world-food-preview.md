# 0.8.0-world-food-preview — генерация и кухня

Добавлены выбранные игроками моды для Forge 1.20.1:

| Мод | Версия | Назначение |
|---|---|---|
| Terralith | 2.5.4 | Разнообразные биомы из ванильных блоков |
| Tectonic | 3.0.17 | Масштабный рельеф с интеграцией Terralith |
| Lithostitched | 1.4.11 | Обязательная библиотека Tectonic |
| Farmer's Delight | 1.3.4 | Культуры, кухня, нарезка и блюда |
| Brewin' and Chewin' | 3.2.1 | Ферментация, напитки и дополнительные блюда |

Всего 68 внешних JAR в клиентском составе; с профилем shaders — 69 JAR и ZIP шейдера. Все 63 прежние записи lock сохранены без изменений. Новые версии и SHA-256 зафиксированы; Lithostitched включён явно, поскольку обязательная зависимость объявлена внутри JAR Tectonic, но отсутствует в его ответе Modrinth API. Манифесты всех пяти JAR проверены.

## Установка — новый мир

Для Legacy Launcher на Windows начните с [пошаговой инструкции](INSTALL-LEGACY-WINDOWS.md) или `START-HERE.txt` в архиве.

Схема сохранений повышена с 2 до 3. Автоматический перенос из 0.7 и более ранних версий заблокирован существующей проверкой установщика. Исходные экземпляры и миры не изменяются. Не копируйте старый мир вручную в эту сборку: совместимость такой миграции не проверена, а автор Terralith рекомендует новый мир.

Из распакованного bootstrap, в Windows:

```powershell
py tools/install.py --side client --visuals shaders --destination "E:\Minecraft\Expedition-0.8-world-food"
```

Для отдельного сервера используйте `--side server`, другую новую папку и опустите `--visuals shaders`. Версии платформы прежние: Minecraft 1.20.1, Forge 47.4.10, Java 17. Установку Forge и запуск см. в README. Новая папка назначения не должна существовать.

## Готовка и баланс

Рецепты и эффекты еды пока штатные. Новых квестов, открытия ингредиентов по боссам или ограничения «одно блюдо + один напиток» нет. Farmer's Delight 1.3 изменил Nourishment и заменил Comfort в своих блюдах на Nourishment; совместный эффект лечения, магии и боевых напитков ещё требует игры с участниками. Наличие эффектов не означает подтверждённую совместимость их боевого поведения с Epic Fight.

Geophilic, Farmer's Respite, HBM и Jade этим обновлением не добавлены. Предыдущий план настройки GT и каталога Chipped остаётся отдельной работой; ускорения GT здесь нет.

## Проверки

- Пять тестов установщика прошли, включая запрет миграции между схемами сохранений.
- Клиент с профилем shaders установлен в отдельный экземпляр, хеши проверены. Графический клиент ещё не запускался.
- Отдельный сервер с новым миром успешно запущен на Java 17 / Forge 47.4.10: 4/4 KubeJS server scripts, 0 ошибок скриптов, 0 failed recipes; 9 глав / 99 квестов.
- Включён `tectonic/tectonic/overlay.terratonic`. Команды locate нашли `terralith:lavender_forest` [3664, 100, 2304] и `explorify:tavern` [-1600, ~, 784]. Это проверка поиска, не визуальная проверка всех структур.
- На реальном экземпляре 0.7 проверен отказ миграции до создания новой папки.
- В логе остаются предупреждения старого состава о клиентских классах/M&A/LDLib и дублирующемся рецепте GT--. После поиска биома зафиксировано отставание тика примерно на 8 секунд; производительность не объявляется проверенной.

Полная доступность руд GT, растений, всех данжей и целей квестов, внешний вид рельефа, производительность вчетвером и прохождение кухни пока не подтверждены. Это preview для проверки, не завершённый баланс.

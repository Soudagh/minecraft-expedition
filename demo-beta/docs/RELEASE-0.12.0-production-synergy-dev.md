# 0.12.0-production-synergy-dev

Электроника RS стала общей производственной цепочкой Create/GT. Ранние заготовки процессоров собираются смесителем, позднее их серийно выпускает сборщик LV. Изменены компоненты энергетики CreateAddition; описания квестов соответствуют рецептам.

## Изменения

- Убраны три ручных shapeless-рецепта raw_basic/improved/advanced_processor. Добавлены три Create mixing без нагрева и три GT assembler: binding + железо/золото/алмаз + кремний forge:silicon + редстоун → 1 заготовка. Обжиг в процессор сохранён. GT: 100 тиков / 16 EU/t.
- Сборщик принимает 2 нити + 144 mB полиэтилена → 16 processor_binding. Старый рецепт слизи на 8 связок сохранён. Химия даёт альтернативу выращиванию слизи, без бесплатных металлических/алмазных процессоров.
- Механический генератор CreateAddition требует mechanical core вместо andesite alloy. Мотор требует lv_electric_motor. Их mechanical crafting переписан явно с сохранением остальных деталей и раскладки; replaceInput не применился к этому типу рецепта в текущем составе.
- Оба варианта аккумулятора вместо brass casing используют lv_machine_hull. Мотор и аккумулятор требуют этап V при размещении/ПКМ; генератор доступен до LV.
- Сохранены 178 квестов / 213 задач / 21 глава, предметные определения 0.11 не изменены. Пояснения склада, сборщика и энергетики обновлены. Победы и девять материалов не переименованы.

[Рецепты и распределение ролей модов](PRODUCTION-SYNERGY.md).

## Валидация

Все внешние mod entries/хеши и save_schema=4 сохранены. Прошли 9 тестов установщика, 3 контракта прогрессии, проверка графа и ID; отдельно сравнены все 178 task sets с установленной 0.11. Новая отдельная серверная установка instances/production-synergy-0.12-check использует копию QA-мира и libraries прежнего теста; исходный экземпляр не изменён. Итог startup-012-passed.log: 65 успешных утверждений, SYNERGY_AUDIT_COMPLETE, 0 event errors, 0 failed recipes (31 added / 56 removed / 194 modified). Четыре фактических энергетических рецепта проверены: два аккумулятора и собственные mechanical crafting генератора/мотора.

Проверяется фактический каталог рецептов, а не только наличие JavaScript: отсутствие старых shapeless, ингредиенты и выходы mixing/assembler, отсутствие требования нагрева, сохранённый обжиг и native binding, количества полимера, все рецепты энергетики и функция определения серверного этапа. QA-скрипт zz_synergy_audit.js в bootstrap не включён.

## Границы

Регистрация рецептов и серверная проверка их содержимого не равны тесту построенной производственной линии или GUI. Нужны реальная партия в смесителе/сборщике, работа шаблонов RS и измерение энергетического цикла motor–alternator. Бои, магические способности, лут, поздние HBM и финальный работающий проект ещё не завершены. OOM генерации нового мира из 0.10 остаётся открытым.

Обновление — только на копии остановленного экземпляра, с полным перезапуском клиента/сервера. Старые сохранённые заготовки не удаляются; новые рецепты действуют на следующие партии. Bootstrap локальный, публикация в GitHub Releases не выполнялась.

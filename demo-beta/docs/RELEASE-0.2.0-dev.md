Замена магической ветки: Mana and Artifice **3.1.11** + Hex Casting **0.11.4 (beta)** вместо Iron’s Spells и Iron’s Lib. Всего 40 модов; добавлены зависимости Inline и PAUCAL. Остальные версии сохранены, включая совместимый с Botania Patchouli 85.

В книге теперь 20 квестов: добавлены независимые вводные пути M&A и Hex. Финальный боевой квест использует Незеритового монстра Cataclysm как предварительное испытание; зависимость начала боевой ветки от производства снята. Сложность босса для четверых ещё не настроена. Удалены старые таблицы лута и фильтры Iron’s Spells.

**Только новый временный мир.** Автоматическое обновление экземпляра 0.1.x заблокировано: удаление мода несовместимо с обещанием сохранения всех его предметов и сущностей. Старый экземпляр остаётся нетронутым. Для будущих совместимых обновлений механизм копирования мира сохраняется.

Полёт, массовая добыча, сильные комбинации и ресурсные этапы пока не сбалансированы. Клиентский вход и прохождение вчетвером требуют отдельного теста. Инструкция установки — README внутри архива.

Проверка 7 октября: сервер создаёт и повторно открывает мир, загружает 20 квестов и скрипты без ошибок KubeJS. Новые предметы и босс существуют в runtime-реестре. Флаг завершения, установленный консольной функцией, сохранился после перезапуска. Проверены SHA-256 всех 40 JAR и защитный отказ обновления с несовместимой схемы сохранений. Не проверены визуальное уведомление и естественное завершение квестов игроками. В логах остаются нефатальные сообщения библиотек и внешних запросов модов.

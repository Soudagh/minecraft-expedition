# Экспедиция · полная сборка

**0.15.0-combat-sustain-dev** — рабочая версия баланса и квестов всей сборки. Формат демо отменён. Minecraft **1.20.1**, Forge **47.4.10**, **Java 17**. Состав 0.9 сохранён: 71 клиентский / 64 серверных внешних JAR с фиксированными хешами; необязательный профиль shaders добавляет Oculus и Complementary.

## Что изменилось

- Настроены пять заклинаний Iron’s: лечение по области, полное лечение, щит, корни и замедление. Базовый Heal сохранён; нативные эффекты и остальные заклинания сверяются с исходными замерами.

- M&A и Hex привязаны к общим этапам; использование найденной экипировки проверяется, снятые вещи возвращаются в инвентарь или сохраняются в личном резерве с полным NBT.

- Каст Iron’s проверяется по общему этапу: Rare III, Epic VI, Legendary VII, восемь отдельных ограничений эффектов. Чернила и выбранная экипировка используют материалы кампании. Добавлены семь необязательных целей боевых ролей.

- Заготовки RS собираются смесителем Create или сборщиком GT; полимеры дают альтернативу слизневой связке. Энергетические компоненты CreateAddition связаны с Create/GT. Подсказки квестов обновлены.

- Книга охватывает кухню, склад и автокрафт, энергетику, HBM, магические специализации и производство GregTech до UV. Всего 22 главы / 185 записей, включая архив и справочные карточки; добавлено 61 предметное задание и 18 задач кампании: победы и материалы.
- Тиара Botania требует корпус EV, wireless grid RS — корпус HV. Базовый контроллер RS остаётся на LV; наковальни iron/lead и пресс HBM — на MV.
- Квест начала электричества больше не запускает финал демо. Старые уведомления при входе отключены. ID предметов, квестов, задач и старые данные прогресса сохранены.
- Девять основных боссов остаются маршрутом RPG. Chaos Guardian, Wither Storm и Clockwork не установлены. NanoMuscle/QuarkTech — варианты специализации, не обязательная броня всех игроков.

**Статус:** книга, общие боссовые флаги, материалы и ограничения корпусов реализованы; ограничения магических способностей/лута, баланс еды и полное прохождение вчетвером ещё не завершены. Зависимость квеста не является серверным запретом крафта. Не начинайте основной долгосрочный мир до проверки всей прогрессии.

## Установка

Скачайте [bootstrap 0.15](https://github.com/Soudagh/minecraft-expedition/releases/download/v0.15.0-combat-sustain-dev/expedition-0.15.0-combat-sustain-dev-bootstrap.zip) из [промежуточного релиза GitHub](https://github.com/Soudagh/minecraft-expedition/releases/tag/v0.15.0-combat-sustain-dev) или исходники именно этой версии. Папка `demo-beta` в исходниках и `expedition-demo` в старом формате архива сохранены как технические имена. В Windows нужны Python 3.10+ и Java 17. Из папки сборки:

```powershell
py tools/install.py --side client --destination "D:\Minecraft\Expedition-0.15" --visuals shaders
```

Для клиента без шейдеров уберите `--visuals shaders`. First-person Model исключается при Epic Fight. В macOS/Linux используйте `python3` вместо `py` и собственный путь. Папка назначения не должна существовать. Установщик загружает JAR с проверкой SHA-256 и создаёт исправления функций Souls like Bosses; одного ручного копирования JAR недостаточно.

Если Python сообщает об ошибке сертификата, выполните `py -m pip install --upgrade truststore`, затем повторите установку. Проверку HTTPS не отключайте.

В лаунчере выберите Minecraft 1.20.1, Forge 47.4.10 и Java 17, укажите установленную папку как игровую директорию. Начните с 8 ГБ памяти для клиента. Все игроки должны использовать одну версию сборки. [Подробная инструкция Legacy](docs/INSTALL-LEGACY-WINDOWS.md).

## Сервер и общий прогресс

```powershell
py tools/install.py --side server --destination "D:\Minecraft\Expedition-server-0.15"
```

Скачайте [Forge Installer 1.20.1-47.4.10](https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.10/forge-1.20.1-47.4.10-installer.jar). В папке сервера выполните `java -jar ПУТЬ-К-INSTALLER.jar --installServer`, затем используйте созданный `run.bat`/`run.sh`. В `user_jvm_args.txt` можно начать с `-Xms2G` и `-Xmx8G`.

При первом запуске прочтите [Minecraft EULA](https://aka.ms/MinecraftEULA); если принимаете её, измените `eula.txt`. Настройте whitelist, сложность hard и резервное копирование. Создайте одну команду FTB Teams и пригласите всех четверых до начала квестов. Предметные цели общие, вещи не изымаются.

Для обновления полностью перезапускайте игру и сервер, не используйте `/reload`. Бой: выберите Battle Mode Epic Fight в управлении, изучите подсказки оружия и навыков. Карта — M, вид от третьего лица — F5. Отключение радара существ и пещер Xaero пока настраивается в интерфейсе вручную.

## Обновление и сохранения

Схема сохранений **4**, как у 0.9. Для тестового обновления 0.9 → 0.15 остановите клиент/сервер, дождитесь выхода Java, сделайте отдельную резервную копию экземпляра. Затем из новых исходников:

```powershell
py tools/install.py --side server --from-instance "D:\Minecraft\Expedition-server-0.9" --stopped --destination "D:\Minecraft\Expedition-server-0.15"
```

Для клиента используйте `--side client`. Установщик копирует весь экземпляр в новую папку, исходная папка остаётся для отката. Изменённые вручную управляемые файлы требуют ручного объединения. `--stopped` подтверждает остановку; установщик не останавливает Java и не проверяет процессы.

Автоперенос из 0.8 и более ранних версий запрещён: в 0.9 удалены AE2/GuideME/GTMThings/GT--, изменён состав. Для них нужна новая папка и новый временный мир. Смену UUID, режима авторизации и удаление модов не совмещайте с обычным обновлением.

## Разработка и проверка

```text
python3 tools/build_quests.py
python3 tools/validate_quests.py
python3 tools/test_install.py
python3 tools/test_progression.py
python3 tools/package.py
```

`tools/resolve.py` пересчитывает версии и не нужен игрокам. Не запускайте его для обычной установки. Источники каждого мода указаны в `mods.lock.json`; JAR, кеши и миры не распространяются в bootstrap.

История предыдущих версий остаётся в `docs/RELEASE-*.md`. Старые BALANCE-0.4/PROGRESSION/RPG-ROADMAP описывают прежние планы; актуальный документ — [FULL-BALANCE.md](docs/FULL-BALANCE.md). Технические проверки не заменяют прохождение и оценку боя.

# Экспедиция: демо 0.1.0-dev

Minecraft **1.20.1**, Forge **47.4.10**, **Java 17**. 38 модов с фиксированными версиями. Это исходники и загрузчик прототипа, не проверенный релиз для долгой игры.

## Установка на другом компьютере

1. Скачайте исходники GitHub через Code → Download ZIP и распакуйте.
2. Установите Python 3.10 или новее и Java 17. В Windows Python должен быть доступен через `py`.
3. Из папки `demo-beta` запустите:

```powershell
py tools/install.py --side client --destination "D:\Minecraft\Expedition-demo"
```

На Linux/macOS используйте `python3` и свой путь, например `~/Games/Expedition-demo`. Папка назначения должна ещё не существовать. Нужен интернет: JAR-файлы загружаются с официальных площадок и проверяются по SHA-256. При ошибке сертификата исправьте сертификаты Python; не отключайте TLS-проверку.

4. В лаунчере создайте профиль Minecraft 1.20.1 с Forge 47.4.10, Java 17, укажите установленную папку как игровую директорию. Не смешивайте её с другими сборками. Начните с 8 ГБ памяти для клиента; уточним по тестам.
5. Все игроки должны использовать один и тот же архив/commit сборки. Точные пункты меню Legacy зависят от версии лаунчера; установка профиля в нём пока не проверена.

## Отдельный сервер

```powershell
py tools/install.py --side server --destination "D:\Minecraft\Expedition-server"
```

Скачайте [официальный Forge Installer 1.20.1-47.4.10](https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.10/forge-1.20.1-47.4.10-installer.jar). В папке сервера выполните `java -jar ПУТЬ-К-INSTALLER.jar --installServer`, используя Java 17. Установщик Forge создаст `run.bat`/`run.sh`.

Запустите сервер один раз. Прочтите [Minecraft EULA](https://aka.ms/MinecraftEULA); только если принимаете её, измените `eula.txt`. Условия автоматически не принимаются. Настройки авторизации загрузчик не меняет.

В `user_jvm_args.txt` можно начать с `-Xms2G` и `-Xmx8G`. Перед общим тестом настройте whitelist, сложность hard и резервное копирование. Сервер настраивайте отдельно, файлы мира не помещайте в GitHub.

В FTB Teams создайте одну команду и пригласите всех четверых **до прохождения квестов**. Квесты совместные. Финальный флаг и уведомление рассчитаны на одну экспедицию на сервер.

## Что есть в прототипе

- Create → механическое ядро → рунический алтарь Botania → настроенное ядро → корпус LV GregTech. Исходный корпус входит в стоимость ядра, остальные компоненты GregTech сохраняются.
- 16 квестов: строительство, механика, мана, боевое испытание Мёртвого короля и начало электричества.
- После последнего квеста: титр, звук и сообщение. Игроки офлайн получат уведомление при входе; флаг хранится в мире.
- Начальная фильтрация сильного сундукового лута; удалены рецепты и обычный лут трёх пушек Cataclysm. Это ещё не полный аудит способов получения и применения вещей.
- Декор Chipped/FramedBlocks доступен сразу; наград бесплатными ресурсами нет.

**Что ещё требует проверки:** запуск мира, клиентские конфликты, все рецепты перехода LV, альтернативные способы получения сильного лута, заклинания/полёт/торговля, генерация данжей, бой вчетвером, длительность прогрессии. Само наличие модов и квестов не гарантирует баланс. В Cataclysm есть технологические атаки боссов; запрет оружия игрока не убирает их.

## Обновление с сохранением мира

Полностью остановите клиент и сервер, дождитесь сохранения и выхода процесса Java. Отдельно скопируйте весь экземпляр на другой диск. Затем из НОВОЙ версии исходников:

```powershell
py tools/install.py --side server --from-instance "D:\Minecraft\Expedition-server" --stopped --destination "D:\Minecraft\Expedition-server-next"
```

Загрузчик копирует **весь экземпляр**, затем обновляет только свои файлы. Исходная папка не меняется. Сохраняются мир, инвентари, данные FTB, scoreboard, настройки сервера. При изменённых вручную управляемых файлах обновление останавливается: потребуется ручное объединение конфигов. Флаг `--stopped` — ваше подтверждение остановки; процесс Java автоматически не останавливается и отсутствие процесса не проверяется.

Сначала запустите новую копию и проверьте базу, инвентарь и квесты. Не запускайте два сервера с одним портом одновременно. Для отката остановите новую копию и используйте старую; изменения, сделанные уже после обновления, в старой копии отсутствуют.

Стабильные ID предметов/квестов сохраняем между версиями. Это правило проекта, а не гарантия совместимости любых будущих модов: смена версии Minecraft, удаление модов и изменения генерации потребуют отдельной проверки миграции. Никнеймы и режим идентификации игроков при переносе менять нельзя без миграции UUID.

## Для разработки

`tools/resolve.py` — только для автора: пересчитывает версии. Игроки используют только `tools/install.py` и готовый `mods.lock.json`.

`python3 tools/build_quests.py` воспроизводит книгу квестов; ID не менять. `python3 tools/test_install.py` проверяет сохранение файлов мира при обновлении и отказы при опасных путях/перезаписи.

JAR-файлы и Minecraft не распространяются в репозитории. Источники каждого мода указаны в `mods.lock.json`; права принадлежат их авторам. Интеграция квестов использует [официальный FTB XMod Compat API](https://kubejs.com/wiki/addons/ftb-xmod-compat).

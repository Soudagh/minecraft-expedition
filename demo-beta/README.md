# Экспедиция: демо 0.6.0-combat-preview

Minecraft **1.20.1**, Forge **47.4.10**, **Java 17**. 51 мод с фиксированными версиями. Это исходники и загрузчик прототипа, не проверенный релиз для долгой игры.

В 0.3 добавлены полный Souls like Bosses, The Graveyard и EEEAB’s Mobs. В 0.4 книга расширена до 8 глав и 83 записей: задания на предметы, ручная практика и атлас. [Состав, места поиска и план этапов](docs/BOSSES.md). Новые бои ещё не сбалансированы под четверых; Chaos Guardian и Wither Storm отложены.

**Используйте установщик:** он создаёт необходимые исправления 113 функций Souls like Bosses. Простое копирование JAR их не установит. Для обновления полностью перезапускайте игру/сервер, не используйте `/reload`. [Проверки и ограничения 0.4](docs/RELEASE-0.6.0-combat-preview.md).

## Боевой тест 0.6

Добавлены Sword Soaring 20.14.2.8, Epic Fight 20.14.17 и Invincible Lib 20.14.8.2. Better Combat заменён; Combat Roll оставлен для сохранения зачарований. First-person Model автоматически исключается из новой копии, шейдеры сохраняются. Для 75 обычных и рунических оружий Simply Swords добавлены базовые боевые типы.

**Это combat-preview, не готовый баланс выживания.** Для демонстрации создайте отдельный творческий мир, включите Battle Mode Epic Fight, возьмите Vatansever и посмотрите его подсказку Shift. Сами установка/обычный меч не открывают все эффекты и навыки. [Управление, проверка и команда обновления](docs/SWORD-SOARING.md).

## Новое в 0.5 (сохранено)

Explorify добавляет таверны, лагеря, руины, башни и мавзолеи на новой территории. Пересоздавать мир не нужно. Некоторые поздние структуры и комната таверны с лутом древнего города отключены. [Подробнее и кандидаты на боевые анимации](docs/STRUCTURES-AND-COMBAT.md).

16 ручных упражнений заменены конкретными целями с количеством предметов и посещением структур. Старые отметки сохранены в необязательном архиве. Всего 9 глав / 99 записей с учётом архива. [Актуальные цели](docs/QUESTS-0.5.md). Информация о прежних обновлениях ниже сохранена для справки.

## Исправление 0.4.1 (сохранено)

При установке профиля `shaders` Complementary выбирается и включается автоматически, если настроек Oculus ещё нет. Существующий выбор пользователя сохраняется. Моды, квесты и баланс не изменены относительно 0.4.0.

## Новое в 0.4

Добавлены шесть глав: экспедиции, мастерская Create, Mana and Artifice, Hex Casting, снабжение Botania и подготовка индустрии. [Перечень заданий](docs/QUESTS-0.4.md). Существующие квесты и их прогресс сохранены. Старое уведомление теперь говорит о рубеже прототипа, а не завершении всей сборки.

[План ресурсных этапов и балансировки](docs/BALANCE-0.4.md): RPG до пятого босса, затем переход к электричеству. Новые ограничения рецептов и фиксация побед всей команды ещё не реализованы.

Необязательные клиентские профили: First-person Model; Oculus + Complementary Reimagined. Добавьте `--visuals first-person shaders` к команде установки, чтобы получить оба. [Инструкция, ограничения и удаление профилей](docs/VISUALS.md). По умолчанию состав модов прежний.

## Карта и анимации из 0.3.2

Исправлен подтверждённый клиентский конфликт GregTech 7.5.3 со старой Xaero’s World Map 1.38.8: отсутствовал `xaero.lib.client.gui.widget.Tooltip`. Обе карты заменены современными: World Map 1.47.0 и Minimap 26.6.0, со встроенной XaeroLib 1.7.3. Анимации Not Enough Animations 1.12.6 сохранены.

Карта — M, вид от третьего лица — F5. Новая мини-карта — обычная, не старая Fair-Play: для сохранения выбранного режима исследования отключите радар существ и режим пещер в настройках карты. Автоматическая фиксация этих ограничений ещё не реализована. Серверный состав не меняется.

Проверены JAR, хеши и наличие отсутствовавшего класса. Полный запуск клиента с новой парой ещё не подтверждён. Установка через `--from-instance` переносит мир и настройки в новую папку; старый экземпляр остаётся для отката.

## Установка на другом компьютере

1. Скачайте bootstrap-архив из Releases и распакуйте. Также можно скачать исходники GitHub через Code → Download ZIP.
2. Установите Python 3.10 или новее и Java 17. В Windows Python должен быть доступен через `py`.
3. Откройте терминал в папке `expedition-demo` из bootstrap-архива (или `demo-beta` из исходников) и запустите:

```powershell
py tools/install.py --side client --destination "D:\Minecraft\Expedition-demo"
```

На Linux/macOS используйте `python3` и свой путь, например `~/Games/Expedition-demo`. Папка назначения должна ещё не существовать. Нужен интернет: JAR-файлы загружаются с официальных площадок и проверяются по SHA-256. При ошибке сертификата исправьте сертификаты Python; не отключайте TLS-проверку.

4. В лаунчере создайте профиль Minecraft 1.20.1 с Forge 47.4.10, Java 17, укажите установленную папку как игровую директорию. Не смешивайте её с другими сборками. Начните с 8 ГБ памяти для клиента; уточним по тестам.
5. Все игроки должны использовать один и тот же архив/commit сборки. Точные пункты меню Legacy зависят от версии лаунчера; установка профиля в нём пока не проверена.

## Отдельный сервер

```powershell
py tools/install.py --side server --destination "D:\Minecraft\Expedition-server"
```

Скачайте [официальный Forge Installer 1.20.1-47.4.10](https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.10/forge-1.20.1-47.4.10-installer.jar). В папке сервера выполните `java -jar ПУТЬ-К-INSTALLER.jar --installServer`, используя Java 17. Установщик Forge создаст `run.bat`/`run.sh`.

Запустите сервер один раз. Прочтите [Minecraft EULA](https://aka.ms/MinecraftEULA); только если принимаете её, измените `eula.txt`. Условия автоматически не принимаются. Настройки авторизации загрузчик не меняет.

В `user_jvm_args.txt` можно начать с `-Xms2G` и `-Xmx8G`. Перед общим тестом настройте whitelist, сложность hard и резервное копирование. Сервер настраивайте отдельно, файлы мира не помещайте в GitHub.

В FTB Teams создайте одну команду и пригласите всех четверых **до прохождения квестов**. Квесты совместные. Финальный флаг и уведомление рассчитаны на одну экспедицию на сервер.

## Что есть в прототипе

- Create → механическое ядро → рунический алтарь Botania → настроенное ядро → корпус LV GregTech. Исходный корпус входит в стоимость ядра, остальные компоненты GregTech сохраняются.
- 20 квестов: строительство, механика, мана, предварительное боевое испытание Незеритового монстра Cataclysm и начало электричества.
- После последнего квеста: титр, звук и сообщение. Игроки офлайн получат уведомление при входе; флаг хранится в мире.
- Начальная фильтрация сильного сундукового лута; удалены рецепты и обычный лут трёх пушек Cataclysm. Это ещё не полный аудит способов получения и применения вещей.
- Декор Chipped/FramedBlocks доступен сразу; наград бесплатными ресурсами нет.

**Что ещё требует проверки:** клиентские конфликты, полное прохождение перехода LV, альтернативные способы получения сильного лута, заклинания/полёт/торговля, генерация данжей, бой вчетвером, длительность прогрессии. Само наличие модов и квестов не гарантирует баланс. В Cataclysm есть технологические атаки боссов; запрет оружия игрока не убирает их.

## Обновление с сохранением мира

**0.2.0 → 0.3.0:** только добавление модов, прежние версии и схема сохранений 2 сохранены. Используйте копирование в новую папку командой ниже. Новые структуры появятся в новых чанках. Сначала проверяйте копию своего мира; старую папку сохраните для отката.


**Переход с 0.1.x на 0.2.0 автоматически заблокирован:** Iron’s Spells и Iron’s Lib удалены. Старые тестовые экземпляры сохраняйте отдельно. Для этой версии создайте новый временный мир: сохранность удаляемых предметов, сущностей и прогресса без отдельной миграции не гарантируется. Приведённая ниже команда предназначена для совместимых будущих версий с одинаковой схемой сохранений.


Полностью остановите клиент и сервер, дождитесь сохранения и выхода процесса Java. Отдельно скопируйте весь экземпляр на другой диск. Затем из НОВОЙ версии исходников:

```powershell
py tools/install.py --side server --from-instance "D:\Minecraft\Expedition-server" --stopped --destination "D:\Minecraft\Expedition-server-next"
```

Загрузчик копирует **весь экземпляр**, затем обновляет только свои файлы. Исходная папка не меняется. Сохраняются мир, инвентари, данные FTB, scoreboard, настройки сервера. При изменённых вручную управляемых файлах обновление останавливается: потребуется ручное объединение конфигов. Флаг `--stopped` — ваше подтверждение остановки; процесс Java автоматически не останавливается и отсутствие процесса не проверяется.

Сначала запустите новую копию и проверьте базу, инвентарь и квесты. Не запускайте два сервера с одним портом одновременно. Для отката остановите новую копию и используйте старую; изменения, сделанные уже после обновления, в старой копии отсутствуют.

Стабильные ID предметов/квестов сохраняем между версиями. Это правило проекта, а не гарантия совместимости любых будущих модов: смена версии Minecraft, удаление модов и изменения генерации потребуют отдельной проверки миграции. Никнеймы и режим идентификации игроков при переносе менять нельзя без миграции UUID.

## Для разработки

`tools/resolve.py` — только для автора: пересчитывает версии. Игроки используют только `tools/install.py` и готовый `mods.lock.json`.

`python3 tools/build_quests.py` воспроизводит книгу квестов; ID не менять. `python3 tools/test_install.py` проверяет сохранение файлов мира при обновлении и отказы при опасных путях/перезаписи.

JAR-файлы и Minecraft не распространяются в репозитории. Источники каждого мода указаны в `mods.lock.json`; права принадлежат их авторам. Интеграция квестов использует [официальный FTB XMod Compat API](https://kubejs.com/wiki/addons/ftb-xmod-compat).

## Предыдущая техническая проверка 0.1.1-dev

Локальный выделенный сервер создал мир и загрузил 16 квестов. KubeJS применил оба изменения рецепта корпуса LV: и верстак, и сборщик требуют настроенное ядро. Исправления таблиц Iron’s Spells относились только к версии 0.1.1; в 0.2.0 этот мод удалён. Исправление опечатки лестницы Cataclysm сохраняется.

Проверено повторное открытие мира после штатной остановки: `$demo exp_progress` сохранил значение `1`. Проверка выполнена консольной функцией; пользовательский финал квеста и визуальное уведомление ещё не тестировались.

## Магия в 0.2.0-dev

Iron’s Spells и Iron’s Lib заменены на Mana and Artifice 3.1.11 и Hex Casting 0.11.4 (beta), добавлены Inline и PAUCAL. Botania остаётся. В книге две независимые вводные магические ветки. Книга Hex — необязательная поздняя цель, её рецепт требует плод хоруса. Учиться магии можно без неё.

Ограничения полёта, добычи и сильных комбинаций ещё не настроены. Это версия для проверки совместимости, не законченная экспертная прогрессия. Первый ресурсный босс и серверные ограничения этапов пока проектируются.

Полный запуск выделенного сервера и повторное открытие мира с новой парой модов проверены. Загружены 20 квестов, ссылки на новые предметы и босса проверены в реестре игры, флаг завершения сохранился после перезапуска. Остаются нефатальные сообщения модов о клиентских классах, запросе аур M&A и проверке обновлений; лог не полностью чистый. Вход клиента, использование магии и прохождение вчетвером ещё не проверены.

## Первый тест с друзьями

Используйте новый временный мир. Проверьте подключение всех игроков, создание команды FTB Teams и общий зачёт первого квеста. Затем в творческом режиме проверьте открытие справочников M&A/Hex, работу посоха Hex и базового заклинания M&A. Проверьте бой с обычными мобами, перекат, открытие JEI и строительство. Сохраните несколько предметов и построек, перезапустите сервер и проверьте их сохранность вместе с квестом.

Для проблемы запишите версию сборки, действие перед ошибкой и приложите `logs/latest.log`; при вылете также соответствующий файл `crash-reports`. Полезны логи и клиента, и сервера. Перед отправкой просмотрите их на наличие личных данных.
